## 一、需求调研

> 甲方发布需求后，调研客户需求，分析明白可见才有清晰的思路。通常和工艺工程师对接。

### 1. 产品品质要求

- 产品最终要达到的目的及生产中注意保护产品

### 2. 产品生产工艺（关键）

- 工艺制程步骤，包括来料情况
- 分析明白可见才有清晰的思路

### 3. 设备效率与节拍

- 明确节拍要求（PCS/h 或 PCS/min）
- 明确年产能要求

### 4. 设备工作环境

- 能够提供的电压、气压、液压
- 环境温度、湿度、洁净度要求

### 5. 资料调研

- 通过各种渠道找到与设备相关资料或视频来了解工艺流程、步骤、布局、结构等
- 使用思维导图把相关信息截图保存导入
- 重要步骤，不急于做方案画图，目的：参考、借鉴

### 阶段交付物

| 交付物 | 说明 |
|:---|:---|
| 需求规格书 | 品质要求、工艺步骤、节拍、环境条件汇总 |
| 工艺流程图 | 来料 → 各工步 → 成品出料 |
| 节拍分析表 | 各工位耗时分解，识别瓶颈工位 |

### 参考周期

- 小型单机：3–5 天
- 中型单机：1–2 周
- 大型产线：2–3 周

### 常见风险

- 客户需求模糊，口头描述与实际不一致 → 必须形成书面需求规格书并签字确认
- 工艺理解偏差，漏掉关键工序 → 与工艺工程师现场确认来料状态和工艺细节
- 节拍要求过于乐观，未考虑实际瓶颈 → 做节拍分解表，预留 10–15% 余量

## 二、方案拟订

> 设备结构、机构重中之重——决定设备成功与否。

### 1. 方案构思及绘制方案模型图

**设备布局草图**（CAD / PPT / 草图）

**设备机构组成示意图**

- 3D 方案：找现成模型，或设计简易模型，拼凑 3D 方案，作为出 PPT 方案素材（开拔网）

**设备动作简图说明**

### 2. 方案颗粒度标准

> 方案模型做到什么深度算合格？以下为方案阶段必须达到的最低要求。

| 维度 | 最低要求 | 不要求 |
|:---|:---|:---|
| 整体布局 | 整机外形尺寸、各单元位置、人机交互位置 | 精确结构件设计 |
| 机构示意 | 各核心机构的运动原理和驱动方式 | 零件级细节 |
| 关键尺寸 | 节距、行程、工位间距、外形包络 | 公差与配合 |
| 动作流程 | 完整时序图，各工位动作顺序和节拍分解 | PLC 程序逻辑 |
| 选型 | 关键电机、气缸、导轨的初步选型（可后续调整） | 精确校核计算 |
| 干涉 | 运动极限位置无干涉 | 细节干涉排查 |

### 3. 方案规格书和 PPT 制作

> 做出大致样子，一般公司有模板。

- 整机结构布局及技术参数介绍
- 整机动作流程介绍及各单元功能介绍
- 整机时序图及产能节拍预估

### 4. 整机报价

- 机械工程师报成本价，要价通常由商务部门加价报
- 报价清单构成 → 见 §附录B

### 5. 技术协议或设备规格书

- 有的公司需要，有的不需要
- 核心内容：设备技术参数、节拍承诺、验收标准、标准件品牌约定、售后条款

### 阶段交付物

| 交付物 | 说明 |
|:---|:---|
| 3D 方案模型 | 满足颗粒度标准的简易 3D |
| 方案 PPT | 结构布局 + 动作流程 + 时序图 + 节拍预估 |
| 方案规格书 | 技术参数、功能描述、验收条件 |
| 报价清单 | 成本价明细 |

### 参考周期

- 小型单机：1–2 周
- 中型单机：2–3 周
- 大型产线：3–5 周

### 常见风险

- 方案过于理想化，未考虑装配和维护空间 → 布局时预留操作空间和拆装空间
- 节拍预估过于乐观 → 时序图基于保守速度估算，留 10% 余量
- 3D 方案直接用现成模型拼凑，未验证机构可行性 → 关键机构至少做简易运动验证
- 报价遗漏隐性成本（外协、表面处理、包装运输）→ 报价清单逐项核对

## 三、方案评审

### 1. 公司内部评审

| 评估项 | 内容 |
|:---|:---|
| 机构可行性 | 参考方案 PPT，评估各机构是否能实现要求功能 |
| 成本评估 | 方案成本是否在合理范围，是否有降本空间 |
| 投资风险 | 技术风险、交期风险、客户付款风险 |
| 维护成本 | 易损件更换便捷性、维护空间、保养周期 |
| 便捷性 | 操作便利性、人机工程、上料下料方便度 |

### 2. 客户评审

- 给出评审意见
- 记录客户关注重点和特殊要求

### 阶段交付物

| 交付物 | 说明 |
|:---|:---|
| 评审报告 | 各评估项结论 + 风险标注 |
| 评审意见汇总 | 内部 + 客户意见整理 |

### 参考周期

- 内部评审：2–3 天
- 客户评审：3–7 天（取决于客户响应速度）

### 常见风险

- 评审走过场，关键风险未被识别 → 评审必须输出书面报告，参会人签字
- 客户需求理解偏差，评审未发现 → 评审时对照需求规格书逐条核对
- 成本评估不准，遗漏标准件或外协费用 → 报价清单逐项复核

## 四、方案整改与确定

### 1. 方案整改

- 明确整改意见，给出整改方案和日程
- 记录意见来由，追溯根因，记入设备开发日志
- 改革后论证，3D 仿真

### 2. 方案确定

- 根据客户需求确定方案
- 公司通过最终评审确定方案

### 3. 最终报价

- 报价清单（修正后）
- 报价清单构成 → 见 §附录B

### 4. 签合同及技术协议

- 技术协议约定：① 设备需要达到的要求 ② 标准件品牌
- 合同核心条款：交期、付款方式、验收标准、质保期、违约责任

### 阶段交付物

| 交付物 | 说明 |
|:---|:---|
| 整改后 3D 方案 | 响应评审意见修改 |
| 最终方案规格书 | 确认版 |
| 最终报价清单 | 签字版 |
| 合同 / 技术协议 | 双方签字盖章 |

### 参考周期

- 整改：3–7 天（视改动幅度）
- 签合同：1–2 周（商务流程）

### 常见风险

- 整改不彻底，带病进入细化设计 → 整改完成后必须再次评审确认
- 合同条款遗漏验收标准和质保条件 → 技术协议逐条核对
- 标准件品牌约定不明，后续采购扯皮 → 技术协议明确品牌清单或同等替代规则

## 五、细化设计

### 1. 人员分配

> 根据项目规模分配人员。

| 项目规模 | 人员分配方式 |
|:---|:---|
| 大生产线（多台设备） | 经验丰富工程师带头单独做方案设计，几个人分别负责几个单机细化设计 |
| 大单机项目 | 一个人方案设计，细化设计时再一个人协助 |
| 小单机项目 | 单人负责方案及细化设计 |

### 2. 结构 / 机构细化设计（计算、选型）

- 电机、气缸、导轨、丝杆等正式选型计算
- 关键结构件强度/刚度校核
- 最终评审
- 细化设计评审报告输出

### 3. 校核检查清单

> 细化设计完成、提交评审前，设计师自查以下项目。

| # | 检查项 | 要点 |
|:---|:---|:---|
| 1 | 整体布局 | 外形尺寸是否满足约定空间（只能小不能大） |
| 2 | 运动干涉 | 各机构运动极限位置是否干涉，包括线缆/气管走线 |
| 3 | 节拍核算 | 各工位实际耗时是否满足要求（只能慢不能快） |
| 4 | 尺寸标注 | 关键尺寸、配合尺寸、安装尺寸是否完整 |
| 5 | 公差配合 | 轴承配合、销孔配合、导轨安装面公差是否合理 |
| 6 | 选型校核 | 电机力矩/转速、气缸推力、导轨负载是否校核通过 |
| 7 | 标准件确认 | 型号、规格、品牌是否与技术协议一致 |
| 8 | BOM 完整性 | 无遗漏、无重复、数量正确、编码规范 |
| 9 | 机加件工艺性 | 拐角避让、退刀槽、壁厚均匀、加工可行性 |
| 10 | 装配可行性 | 装配顺序合理、工具可操作、无装配死角 |
| 11 | 维护空间 | 易损件可更换、传感器可调整、润滑点可达 |
| 12 | 安全防护 | 运动件防护、急停回路、安全光幕/光栅 |

### 4. 出工程图与 BOM

- 3D 图档转图打包（PDF / dwg / stp / XT 格式；虚拟件打不了包）
- 物料清单：采购清单、材料明细表、焊接清单
- 审图 → 签字归档

### 5. 装配作业指导书

- 装配作业指导书输出及爆炸图制作

### 阶段交付物

| 交付物 | 说明 |
|:---|:---|
| 详细 3D 图档 | 全部结构件、标准件、机构完成细化 |
| 工程图 | 2D 图纸（总装图、部件图、零件图），批量打印用 SW Task Scheduler |
| BOM | 采购清单 + 材料明细表 + 焊接清单 |
| 选型计算书 | 电机、气缸、导轨等关键选型计算记录 |
| 装配作业指导书 | 含爆炸图 |
| 评审报告 | 细化设计评审输出 |

### 参考周期

- 小型单机：2–3 周
- 中型单机：3–5 周
- 大型产线：6–10 周

### 常见风险

- 干涉遗漏（尤其线缆/气管运动状态）→ 运动极限位置必查，有条件做 3D 仿真
- 选型余量不足，调试时发现力矩/推力不够 → 选型计算给足安全系数
- BOM 遗漏导致采购延误 → BOM 审核必须交叉检查
- 公差不合理导致装配困难或间隙过大 → 关键配合面由经验工程师复核

## 六、跟进与落地

### 1. 采购跟进

- 标准件采购周期跟踪（长交期件提前下单）
- 机加件/钣金件外协进度跟踪

### 2. 装配跟进

- 现场指导装配，解决装配干涉和设计缺陷
- 记录装配过程中的问题，及时出工程变更通知单（ECN）

### 3. 调试跟进

- 机械动作调试，确认各机构运动顺畅
- 配合电气/软件联调，确认时序和节拍

### 4. 预验收与终验收

| 阶段 | 预验收（FAT） | 终验收（SAT） |
|:---|:---|:---|
| 地点 | 供方工厂 | 客户现场 |
| 时机 | 设备组装调试完成后 | 设备到客户现场安装调试后 |
| 内容 | 确认设备基本功能、节拍、操作流程 | 确认产能、良率、稳定性，连续运行测试 |
| 参与方 | 供方 + 客户到供方现场 | 供方 + 客户在现场 |
| 周期 | 1–3 天 | 1–4 周连续运行 |
| 交付物 | 预验收报告（客户签字） | 终验收报告（客户签字，触发尾款） |

### 5. 工程变更

- 工程变更通知单（ECN）下发
- 变更原因记录，追溯根因

### 阶段交付物

| 交付物 | 说明 |
|:---|:---|
| 采购进度表 | 各物料到货时间跟踪 |
| 装配问题记录 | 装配过程问题及解决方案 |
| 调试报告 | 节拍实测、功能验证结果 |
| ECN 变更单 | 所有变更记录 |
| 预验收报告 | 客户签字确认 |
| 终验收报告 | 客户签字确认，触发尾款 |

### 参考周期

- 采购：2–6 周（标准件交期决定）
- 装配：1–3 周
- 调试：1–3 周
- 终验收连续运行：1–4 周

### 常见风险

- 长交期标准件未提前下单，导致装配等待 → 方案确定后立即梳理长交期件清单
- 装配干涉频发，设计缺陷集中暴露 → 细化设计阶段严格执行校核检查清单
- 调试时节拍不达标 → 方案阶段时序图留足余量，调试阶段逐工位优化
- 终验收时稳定性不足 → 预验收时充分跑机，发现问题提前解决

## 七、归档与总结

### 1. 项目总结

- 设计经验沉淀（成功点和失败点）
- 成本复盘（预算 vs 实际）
- 交期复盘（计划 vs 实际）

### 2. 资料更新

- 3D 图档、2D 工程图、BOM 最终版归档
- ECN 变更记录归档
- 装配指导书更新（反映调试中的修改）
- 经验教训记入知识库

### 阶段交付物

| 交付物 | 说明 |
|:---|:---|
| 项目总结报告 | 经验、成本、交期复盘 |
| 归档资料包 | 3D + 2D + BOM + ECN + 装配指导书（最终版） |
| 知识库更新 | 经验教训、典型问题、机构参考 |

### 参考周期

- 3–5 天

### 常见风险

- 资料未及时归档，后续维护找不到最新版本 → 项目结束即归档，不拖延
- 经验未沉淀，同类问题在下个项目重复出现 → 总结报告必须包含失败点和改进措施

|:---|:---|:---|

## 附录 B：报价清单构成

> 整机报价费用项明细，机械工程师报成本价时逐项核对。

| # | 费用项 | 说明 |
|:---|:---|:---|
| 1 | 原材料费 | 铝型材、钢材、钣金材料等 |
| 2 | 标准件费 | 电机、气缸、导轨、轴承、螺丝、传感器等（品牌以技术协议为准） |
| 3 | 机加费 | 外协机加工费用（按工序和工时估算） |
| 4 | 钣金费 | 钣金折弯、切割、焊接费用 |
| 5 | 焊接费 | 焊件结构件焊接工时费 |
| 6 | 外协费 | 表面处理（氧化、喷涂、电镀）、热处理等 |
| 7 | 电气费 | 传感器、电机、线缆、接头等（虽非机械设计，报价需含） |
| 8 | 设计费 | 机械设计人工成本（按工时×单价） |
| 9 | 装配调试费 | 装配人工 + 调试工时 |
| 10 | 包装运输费 | 木箱、物流 |
| 11 | 管理费 | 项目管理、场地分摊 |
