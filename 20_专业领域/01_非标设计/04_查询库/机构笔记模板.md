# 机构笔记模板

> **用途**：01_机构库 新增机构笔记时套用。参照库内既有笔记（转盘与分割器 等）实际结构。
> 新建后在 [[机构索引]]「机构速查」表补一行。
> **定位**：机构库记**形态与选型方法**（工况 → 参数 → 决策流程），不记具体项目参数（那是案例的事）。

```markdown
# 【机构名】

## 适用场景
【填：什么工况、节拍、负载范围选它；一句话定位】

## 构成
【填：主要部件清单与作用，如「分割器（入力轴+出力轴+凸轮分度）+ 转盘 + 电机 + 工位夹具」】

## 选型参数
- **【参数1】**：取值/范围 —— 含义
【填：决定选型的核心参数表，每条给范围与工程含义】

## 选型决策流程
1. 【填：第 1 步：确定什么 → 依据】
2. 【填：…每步可量化，末步落到选型结论】
【填：按真实决策顺序编号，7 步封顶，宁缺毋滥】

## 典型故障与对策
| 故障现象 | 可能原因 | 排查方向 |
| :--- | :--- | :--- |
| 【填】 | 【填】 | 【填】 |

## 案例验证
- 【填：哪个案例用过、验证了什么边界（如「安全系数 2.1 后期加检测工位无压力」）】
```

## 写作铁律
- **选型参数要能直接查**：每条带范围/单位，别写空泛描述
- **决策流程可执行**：每步是「确定 X → 依据 Y」，不是感想
- **故障表是活资产**：现场踩过就补，别等整理
- 计算配套（电机/丝杆寿命/同步带）链接到 `03_计算校核/` 对应页，参数不在此重复
