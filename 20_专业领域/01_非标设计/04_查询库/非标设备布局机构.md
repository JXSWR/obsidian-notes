## 通用准则

> 以下为非标设备布局机构设计的通用经验，贯穿全文各章节，先行阅读有助于理解后续机构选型。

| 主题 | 经验 |
|:---|:---|
| 物料轻 | 重力不够时加配重块 |
| 凸轮理解 | 多个凸轮在同一根轴上转动；平面往复运动凸轮相当于把平面转动凸轮展开 |
| 凸轮热处理 | 凸轮需要进行热处理 |
| 凸轮时间表 | X 轴角度，Y 轴位移；起点距离等于回程距离 |
| 双凸轮防干涉 | 一个静止另一个运动；一个运动启动前另一个提前静止（重要） |
| 凸轮插件规范 | 起始角为 0，终止角一定 360；顺序：推程、停止、推程、停止 |
| 连杆设计 | 先设计连杆再设计凸轮；连杆行程并不是凸轮行程 |
| 从动件选择 | 根据速度和负载推断从动件运动形式；摆动型需要弹簧锁合 |
| 定位修正 | 通常需要前期定位，后期修正位置或角度偏差（二次检测） |
| 导向 | 对中定位等机构都必须加导向（导轨或直线轴承） |
| 振动盘 | 发产品给供应商设计加工，材料一般是尼龙；易损件更换方便 |
| 放卷机构 | 还有弹簧阻尼做的放卷机构 |

## 一、设备布局形式

### 分类方案

**直线型布局** — 单通道 / 双通道布局

**环型布局**

| 子类型 | 特点 |
|:---|:---|
| 矩形布局 | 90° 直角转接处用气缸 + 导轨 + 缓冲器 + 硬限位 |
| 圆角矩形布局 | 环形导轨输送线 |

**U 型布局** — 上料和下料位置可布置在同一侧

**工作站形式布局** — 工作站或机架之间用 L 形板 / 侧板连接

### 参数对比

**多工位场景应用**

| 结构 | 说明 |
|:---|:---|
| 转盘结构 | 凸轮分割器为代表，放置不同工位循环往复 |
| 多通道同步移栽机构 | 多个不同工位用同步移栽实现物料转移 |
| 输送线 + 2 工位转盘 | 待料 + 加工 |

### 结构细节

**直线型 — 皮带线结构形式**
- 产品的输送装置通常是输送带或输送链
- 上下顶升 / 左右水平回流线
- 若有夹具随行，要考虑夹具的循环

## 二、回转与分度机构

> 圆周型布局的核心组件。精度取决于圆盘大小（圆盘越大精度越低），取决于自身结构精度，与驱动电机无关。

### 分类方案

**凸轮分割器** — 两种驱动方式

| 驱动方式 | 动静比控制 | 适用 |
|:---|:---|:---|
| 普通电机不停，通过凸轮动静比结构控制转盘角度 | 动静比固定 | 停止时间长、转动时间短差异大的场景不适合 |
| PLC + 控制电机控制停止/运转 | 任意控制动静比 | 应用广泛 |

**其他回转机构**

| 机构 | 特点 | 适用 |
|:---|:---|:---|
| DD 马达（力矩电机） | 电机直连，无传动机构 | 高精度、大力矩 |
| 中空旋转平台 | 本质是减速器，中空若要实现间歇运动必须用控制电机 | 精度要求高，小型结构 |
| 回转支撑 | 齿轮 + 交叉滚子轴承结构 | 重载 |
| 气动分度台（棘轮机构） | — | 低转速 / 低频率 / 低精度 |
| 电动分度台（蜗轮蜗杆） | — | — |
| 伺服 + 传动 | — | 中转速 / 一定精度 / 轻载（加速要求不高），静止状态下刚性要求不高 |
| 自制旋转平台 | 电机 + 传动机构或联轴器带转台旋转 | 不推荐 |

**间歇机构结构形式**：棘轮机构 / 槽轮机构 / 连杆机构 / 凸轮机构

### 参数对比

**凸轮分割器参数**

| 参数 | 说明 |
|:---|:---|
| 等分数（分割数、分度角） | 布局时确定；布局数要多于实际工位数（预留空间，否则干涉） |
| 轴距 | 输入轴与输出轴间的距离；转盘直径不大于轴距的 5 倍（负载小、转速不快可超） |
| 驱动角 | 入力轴与出力轴处于运动状态时入力轴旋转的角度；驱动角越大，时间越长，运行越平稳 |
| 动静比 | 如 120° 驱动角 → 动静比 1:2；180° 分度角 → 动静比 1:1 |

**凸轮运动曲线**

| 曲线 | 类型 | 适用 |
|:---|:---|:---|
| MT | 变形异形曲线 | 高速、轻载 |
| MS | 变形正弦曲线 | 中高速、中载（应用普遍） |
| MCV50 | 变形等速曲线 | 中高速、中载（应用普遍） |

### 结构细节

**凸轮分割器精度特点**
- 有一定精度，工位时间相差不大，适用大部分圆形布局
- 静止刚性有要求
- 应用分类：升降摆动凸轮分割器

**组合形式 — 分度盘 + 压力模块**
- 压力模块：气液增压缸 / 气缸 + 连杆（应用连杆死点位置，自锁原理）
- 支撑结构：气缸 + 连杆（自锁原理）/ 气缸 + 板凸轮 + 支撑顶升机构（凸轮与顶升接触用轴承）

### 配套组件

**搭配电机**

| 电机类型 | 说明 |
|:---|:---|
| 普通电机 | 匹配动静比 |
| 控制电机 | 大部分应用动静比不能匹配，用受力最友好的 270° 驱动角，通过控制电机停止来满足使用要求 |

## 三、上料与供料机构

### 分类方案

| 类型 | 推料/供料方式 |
|:---|:---|
| 弹夹转盘放料机构 | 电机丝杆推料机构 |
| 弹夹料仓重力放料机构 | 笔型气缸 + 仿形推料板机构 |
| 弹夹料仓重力放料 + 螺旋下料 | 电机带动螺旋轴 |
| 弹夹料仓重力放料 + 十字叶片放料 | 电机带动十字片 |
| 托盘（Tray 盘）上料 | 传动模组 + 机械手 |
| 振动盘上料 | 圆振 + 直振 |
| 皮带线上料 | 同步带 / 平皮带 / 倍速链 / 治具回流线 |
| 工业抽屉式 | 工业滑轨 |
| 飞达机构（Feeder） | 收放料卷 |

### 参数对比

**皮带线上料类型**

| 类型 | 说明 |
|:---|:---|
| 同步带 / 平皮带 / 倍速链 | — |
| 治具回流线 | 回流结构：上下结构 / 左右结构 / 斜向结构（靠重力） |
| 治具皮带输送线 | 随行治具连接治具同步带 |

**飞达机构应用行业**

| 行业 | 应用 |
|:---|:---|
| 标签行业 | 供料 |
| 锂电行业 | 隔膜或极片（卷绕机） |
| 半导体行业 | SMT 贴片（贴片机）、编带（编带机–收卷） |

### 结构细节

**托盘上料** — 传动模组（丝杆 / 同步带）+ 机械手
- 料盘仿形（皮带线需给料盘做挡边）→ 上料分盘 → 料盘回收叠盘

**振动盘上料**
- 圆振 + 直振（模块化比较好）；选型直接定制，产品寄给供应商评估打样；组装机居多；材料一般尼龙

**治具皮带输送线细节**
- 高精度高刚性：导轨 + 二次定位
- 随行治具侧面 + 包胶螺丝与耐磨条底板接触保持平衡减少噪音；底面 + 轴承螺丝做导向
- 做回程导轨钣金拖住治具同步带
- 治具同步带可直接购买或定制

**工业抽屉式 — 工业滑轨**
- 选型：负载和行程
- 到位检测（传感器）+ 定位或限位：① 阻挡气缸 + 槽 ② 碰珠卡扣或球形扣 ③ 磁吸
- 需要做外部硬限位，不能依赖工业滑轨自身限位装置

**飞达机构 — 收放料卷**
- 物料贴在料卷（离心纸……）上 → 放卷 / 收卷
- 双层料卷中间夹层物料
- 料卷本身就是物料
- 结构形式：后撤式 / 固定式

### 配套组件

**飞达机构组件**

| 组件 | 说明 |
|:---|:---|
| 气涨轴放卷机构 | 料卷内圈套上面通气涨紧；外加轴座随料卷转动；通气端 + 旋转接头（防止气管轴向拧）；可选择阻尼器或磁粉制动器控制力矩；轴系设计通常两个轴承（经典结构），轴承固定方式 → 见 `公共附录_标准件与通用知识.md` §五 |
| 重力浮动涨紧机构 | 竖直方向直线轴承 + 光轴 + 水平棍子 + 底部弹簧（防止掉落）；水平棍子因重力上下浮动 |
| 纠偏系统（高精度） | 膜位置检测传感器（纠偏传感器–区域对射片式光幕）；传感器反馈给电机带动放卷机构纠偏（前后位移）；无精度要求则用抱箍或滚轮两边导向限位 |
| 卷绕电机选型 | 伺服电机；或力矩电机（普通电机），但无位置/速度控制 |

### 实操要点

- 飞达放卷机构还有弹簧阻尼形式
- 料带式上料、退料式上料、柔性振动盘 + 并联机器人 → 见 §附录B

## 四、来料处理

### 分类方案

| 工序 | 方式 |
|:---|:---|
| 错分 | 对来料挡料错位（震动供料场合居多） |
| 取放料 | 变矩移栽（直线电机 + 双动子）/ 等距移栽 |
| 定位 | 治具顶升 / 靠边 / 对中 / 仿形 / V 形块 |
| 纠偏 | UVW 对位平台 + CCD / 横移机构 + 纠偏传感器 |
| 分料 | 剥离机构 / 螺杆分料机构（绞龙） |
| 缓存 | 弹夹式（料仓间距 = 产品厚度 × 2.5） |

### 参数对比

**定位方式**

| 定位方式 | 说明 |
|:---|:---|
| 治具顶升定位 | 顶升用一个圆柱销一个菱形销；治具若是铝合金，底部安装 45 钢块打销孔更耐磨 |
| 靠边定位 | 一边靠一边气缸推；首选滑台气缸 |
| 对中定位 | 见下方对中机构详表 |
| 仿形定位 | — |
| V 形块 | — |

**对中定位机构**

| 机构 | 特点 |
|:---|:---|
| 正反牙丝杆 | 中间可用联轴器连接 |
| 同步带（经典） | 上下带固定夹紧部件实现同步相向运动，加导轨做导向；用一个电机实现双工位同步对中（一根轴连接两个同步轮驱动）；同步带平放或竖直放置；可同时对中多个产品 |
| 齿轮齿条 | 中间齿轮 + 两边各一根齿条 |
| 连杆 | 中间旋转带动两边连杆运动（电机驱动），或两边移动带动中间旋转（气缸驱动）；导向可以是导轨或直线轴承 |

### 结构细节

**分料方式**
- 剥离机构：料盘或产品与料盘在取料过程中分离
- 螺杆分料机构（绞龙）：间隔/等距、换向（改变方向）

### 实操要点

- 对中定位等机构都必须加导向（导轨或直线轴承）
- 通常需要前期定位，后期修正位置或角度偏差（定位后的微调补偿，通常需要二次检测）
- 检验、排列、成型/加工、排废料 → 见 §附录B

## 九、基本机构

### 1. 凸轮机构

#### 分类方案

**凸轮分类**

| 分类方式 | 类型 |
|:---|:---|
| 按凸轮形状 | 盘形凸轮（含共轭凸轮）、移动凸轮、圆柱凸轮 |

#### 参数对比

**凸轮类型与参数**

| 凸轮类型 | 外形参数 | 运动参数 |
|:---|:---|:---|
| 平面盘形凸轮 | 基圆半径、孔直径、凸轮厚度 | 四阶段：推程、停止、回程、停止（旋回/等待旋回/旋出/等待旋出）；行程 = 大圆半径 − 基圆半径；运动阶段角度和 = 360° |
| 平面盘形沟槽凸轮 | 基圆半径、孔直径、沟槽宽度（配合滚子直径）、凸轮厚度、外圆半径 | 同上 |
| 平面往复运动凸轮 | 起点高度、凸轮厚度 | 三阶段：停止、推程、停止；行程 = 两停止位置高度差（起点 = 终点）；各阶段长度 |
| 空间圆柱凸轮 | 最小半径、孔直径、凸轮槽宽（滚子深度）、凸轮槽深（滚子厚度）、圆柱高度 | 四阶段；行程 = 两停止位置高度差；角度和 = 360° |
| 开放轨迹圆柱空间凸轮 | 最小半径、孔直径、凸轮台阶深（滚子厚度）、圆柱高度（最大高度） | 四阶段；行程 = 两停止位置高度差；角度和 = 360° |
| 空间端面凸轮 | 最小半径（凸轮内径）、凸轮壁厚（滚子厚度）、圆柱高度（起点高度/最低点） | 四阶段；行程 = 两停止位置高度差；角度和 = 360° |

> 平面往复运动凸轮相当于把平面转动凸轮展开后的一种形式。开放轨迹圆柱空间运行凸轮与空间端面凸轮一致。起点距离等于回程距离。

**从动件类型**

| 从动件类型 | 运动方式 | 特点 |
|:---|:---|:---|
| 尖顶 | 直动型 / 摆动型（有支点） | 低速、载荷小、精度高、不耐磨损 |
| 平底 | 直动型 / 摆动型（有支点） | 润滑性好（作用力垂直于切线方向）、高速载荷大、易磨损，凸轮轮廓不能内凹。平顶可用圆盘代替（滑动变滚动），从动件采用分体结构增加材料耐磨性 |
| 滚轮 | 直动型 / 摆动型（有支点） | 低速、载荷大、耐磨损 |

从动件运动轨迹：等速（直线）/ 等加速（抛物线）/ 余弦加速度（简弦）/ 正弦加速度（摆动）

**凸轮机构应用**

| 应用 | 说明 |
|:---|:---|
| 凸轮与凸轮分割器联动 | 凸轮顶升机构：顶升凸轮时间表对应凸轮分割器做运动参数时间表，借助 SW 今日制造插件生成凸轮。凸轮分割器时间表：X 轴为驱动角（转位角度）、停止角 |
| 双凸轮取放机械手 | 顶升凸轮（八阶：取下停止→取上升→取上停止→放下降→放下停止→放上升→放上停止→取下降）；移位凸轮（四阶：移回停止→移出→移出停止→移回）；移动连杆（力锁合绑定在移位凸轮上，作用：放大移位凸轮行程） |

| 凸轮口罩机焊耳机构 | 例 |

**凸轮设计禁忌**

| 禁忌 | 说明 |
|:---|:---|
| 动平衡 | 防止凸轮摆动力矩大，可挖孔减重或配重 |
| 安装孔键槽 | 朝向结构强度大的一面 |
| 运动轨迹 | 尽可能平缓；行程越大，压力角越大，轨迹越陡峭有急弯现象 |
| 沟槽凸轮 | 底面和侧面不能太薄，防止淬火后内凹变形或断裂（HRC50）；推程回程滚子与沟槽内外侧面接触导致润滑不好，采取上下滚子错位用一根轴穿起来（上滚子与内侧面接触，下滚子与外侧面接触） |
| 材料选择 | 高耐磨高硬度，主动件比从动件硬度高 3–5 度，不能相同硬度。搭配：凸轮铸铁/从动件青铜；凸轮淬硬钢/从动件软青铜或黄铜或尼龙 |
| 设计顺序 | 先设计连杆再设计凸轮 |

#### 实操要点

- 凸轮时间表绘制：X 轴角度，Y 轴位移；可借助 Auto CAD 或今日制造插件辅助绘制（根据时间表自动生成）；可绘制多个凸轮联动的时间表
- 凸轮插件规范：起始角为 0，终止角一定 360；顺序：推程、停止、推程、停止
- 根据移位凸轮设计移位连杆，连杆行程并不是凸轮行程
- 防止两个凸轮运动干涉——一个静止另一个运动；一个运动启动前另一个提前静止（重要）
- 凸轮需要进行热处理；易损件更换方便
- 从动件安装位置与压力角有关（压力角越小越好）；摆动型需要弹簧锁合

## 附录 A：SW 机构设计

> 软件工具操作，与机构理论主体分离。

### 布局与运动算例

**流程**

1. 新建 → 装配体 → 生成布局
2. 画草图 → 退出草图
3. 新建运动算例 → Motion 分析
4. 新建马达 → 运动计算 → 播放 ▶️（有必要可生成轨迹曲线）
5. 接触设置

**布局界面下新建零件**

1. 编辑零件 → 编辑草图 → 转换实体引用
2. 无需退出草图，点击特征 → 拉伸实体
3. 到装配体，查看右键点击浮动
4. 配合约束 → 新建运动算例

**注意事项**
- 今日制造插件默认四阶，选择添加阶段，同时各阶段选择从动件运动形式
- 按照插件给的顺序：联动时间表同样都是推程开始（推程、停止、回程、停止）
- 如果外部参考选不上，打开过滤器
- 布局模式下画草图
- 若是时间短，移动键码往右，重新计算
- 线框模拟 / 实体模拟
