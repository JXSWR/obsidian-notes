# 非标设备结构及选型

---

## 一、焊件结构件
### 1. 机架

#### 框架

| 材料 | 连接方式 | 表面处理 | 关键要点 |
|------|---------|---------|---------|
| Q235方通 | 焊接 | 烤漆 / 喷电镀白（不易生锈） | 壁厚一般2–2.5mm（经验值） |
| 不锈钢方钢 | 焊接 | — | 焊接垫块后整体上铣床铣平面 |
| 铝合金型材 | 角码组装 | 本色阳极 | 型材外轮廓无精度，要用槽定位（槽精度高） |

**Q235方通机架设计要点：**

- 机架上方方通上焊接垫块，然后整体上铣床铣平面，保持高度一致
- 垫块焊接位置：①焊接到方通上方 ②焊接到两个方通组合拐角处，比方通高出一些，然后攻牙连接大板
- 方通端面封顶盖一般采用内封，采用焊接工艺
- 机架底部钣金上开孔（40–50mm）走线或气管

> ⚠️ **安装大理石**：机架与大理石之间需放置橡胶垫；大理石与机架垫块连接需大理石打孔并装丝套；大理石和大理石之间不用加橡胶垫。需要打吊装孔和过线孔。

**机架结构设计两种方式：**

| 方式 | 说明 |
|------|------|
| 包边式 | 外罩套在机架上，底板预留框架位置，四周单边预留5mm间隙 |
| 嵌入式 | 框架打孔锁付在机架上 |

> ⚠️ **竖直方通通底面**：底面安装底板方便（设计经验），上面随意。

#### 门板 / 侧板 / 底板 / 顶板

- 底板或顶板打大孔走线走气

#### 设备大板

| 材料 | 表面处理 | 关键特性 | 典型应用 |
|------|---------|---------|---------|
| 45钢 | 镀铬 / 镀镍 / 发黑 / 磷化 | 刚性好、可加工 | 常规设备大板 |
| 大理石 | — | 高精度、防震 | 视觉检测设备（90%使用） |

**大理石平台设计要点：**

- 防震措施：防震脚杯 / 大理石与框架间用胶垫
- 精度等级：000 / 00 / 0 / 1级（检测平台常规是00级）
- 视觉检测设备一般厚度150mm以上，最少120mm
- 需要打吊装螺丝
- 接触面涂清漆防锈，工程图注明

#### 电气元件安装板

- 材料：镀锌板
- 厚度：1.5–2mm
- 装电子元器件，打自攻螺丝

#### 支撑——脚轮 / 脚杯 / 安装板

**选用标准**：按照承载、单向或万向、一体式或分体式、是否带刹车。

**脚轮脚杯组合方案：**

| 组合 | 适用场景 |
|------|---------|
| 两个万向轮（不带刹车）+ 两个定向轮 | 设备 |
| 四个万向轮（不带刹车） | 设备（更容易移动） |
| 两个万向轮（带刹车）+ 两个定向轮 | 移动小车 |
| 福马轮 | 不经常移动的小车（调平容易，上下行程范围很小） |

**安装位置**：脚杯靠外方便调节，放在机架支撑位；脚轮靠里，脚轮旋转最大范围不得干涉脚杯。

安装板厚度一般15–20mm。

### 2. 内部架构

#### 设备大板

同机架设备大板（45钢镀铬/镀镍/发黑/磷化，大理石可做靠边定位）。

#### 焊件支撑结构——龙门架

- 四个支撑底板底部，其中一侧的两个打定位销定位，防止过定位，增加刚性
  - 两个圆柱销：一个圆孔 + 一个腰形孔
  - 一个圆柱销 + 一个菱形销：两个圆孔
- 龙门架上方安装面与底部安装面平行度0.1–0.2
- 焊接加强筋

#### 传感器型材

- 安装有专门的感应器铝合金型材（配合型材螺母），淘宝或怡合达（ADG01–609）
- 固定方式：型材打腰形孔做可调

## 五、动力源
### 1. 电机与减速器

#### 1. 普通电机

#### 直流电机

| 类型 | 换向方式 | 关键特性 | 典型应用 |
|------|---------|---------|---------|
| 永磁直流电机 | 碳刷+换向器 / 无刷 | 结构简单、调速方便 | 小功率场合 |
| 励磁直流电机 | 碳刷+换向器 | 力矩大 | 需要大启动转矩场合 |

#### 交流电机

| 类型 | 子类 | 额定转速 | 关键特性 |
|------|------|---------|---------|
| 三相异步电机 | — | 1440–1480（计算按1400） | 非标最常用，磁场实际转速1500 |
| 单相异步电机 | — | 1200 | 小功率、单相供电场合 |
| 同步电机 | 电励磁 / 磁阻 / 永磁 | 与磁场同步 | 转速恒定、无滑差 |

> ⚠️ **异步 vs 同步**：异步电机转子转速与旋转磁场存在滑差；同步电机转子转速与旋转磁场等速。异步电机在磁场转速与实际转速相差大时力矩增大，有一定过载能力。

#### 调速电机

| 调速方式 | 原理 | 额定转速 | 关键特性 |
|---------|------|---------|---------|
| 调压调速 | 电压控制 | 通常1200 | 低于400转散热不好；有可频繁启停型号 |
| 变频调速 | 改变输入电流频率 | — | 通常为三相异步电机；配变频器可频繁启停、正反转 |
| 力矩电机 | 堵转下恒扭矩输出 | — | 常应用于收卷 |

> ⚠️ **调压调速注意**：控制皮带线想要精确控制位移量，可加装旋转编码器滚轮与皮带接触摩擦计量（皮带线+编码器方案）。

变频调速电机的结构特点：轴承强度好、绝缘性好、独立风扇。

#### 刹车电机

两种形式：一种断电刹车（通电阻尼），一种电机+刹车模块。

#### 减速电机

普通电机+减速器的组合。即便使用调速手段（调速器、变频器），也只能在小范围内调速。如需求转速低于额定转速的50%，应加减速机构（减速器、同步轮传动、链轮传动、齿轮传动）。优先选择减速电机（自制机构和减速电机采购没太大区别）。

品牌参考：精研

#### 2. 控制电机

#### 伺服电机

| 参数项 | 内容 |
|-------|------|
| 控制方式 | 自带编码器 / 闭环控制 |
| 低速特性 | 不抖动、不爬行（前提：惯量比合适、结构刚性强） |
| 控制模式 | 速度模式（脉冲频率）/ 位置模式（脉冲数量）/ 力矩模式（电流控制） |
| 额定转速 | 一般3000，最高可达12000 |
| 力矩特性 | 额定转速下恒力矩输出；超过额定转速后恒功率输出 |
| 最大转矩 | 一般为额定转矩3倍，可短时间过载 |
| 堵转转矩 | 电机憋住输出转矩，可做阻尼、保持力、静压力 |
| 制动方式 | 断电刹车（机械式抱闸）/ 再生制动 |
| 接线 | 两根线：电机线 + 编码器线 |
| 品牌 | 汇川 / 台达 |

**闭环控制层级：**

| 控制类型 | 组成 | 说明 |
|---------|------|------|
| 半闭环 | 旋转编码器 + 电机 + 驱动器 | 速度检测 |
| 全闭环 | 旋转编码器 + 电机 + 驱动器 + 直线编码器 | 位置检测 |
| 开环 | — | 无反馈 |

**惯量比参考：**

| 惯量比 | 适用场景 |
|--------|---------|
| 不超过30 | 能用：移栽模组、放置模组、点对点位移（不涉及装配工艺） |
| 10左右 | 线速度较快 |
| 5以内 | 响应速度快：电缸压机 |

**伺服电机种类：**

| 种类 | 说明 | 典型应用 |
|------|------|---------|
| 交流无刷同步伺服 | 高转速、长寿命、低噪音、高稳定性、结构简单（便宜） | 应用最广泛 |
| 交流无刷异步伺服 | 大输出功率、高转速 | 主轴使用（非标自动化） |
| 直流碳刷/无刷同步伺服 | — | — |

**驱动器类型：**

| 类型 | 功能 |
|------|------|
| 多功能型 | 功能全面 |
| 通用型 | 不能外接编码器（光栅、磁栅）、传感器，能做三环控制 |
| 位置型 | 不能外接编码器、传感器，只能做脉冲控制 |

#### 步进电机

| 参数项 | 内容 |
|-------|------|
| 控制方式 | 脉冲控制，开环 |
| 低速特性 | 低速震动（解决：加减速器 / 细分 / 加阻尼） |
| 高速特性 | 力矩骤减 |
| 速度范围 | N一般取120～600转 |
| 组成 | 步进电机 + 驱动器 + 驱动电源 |
| 适用场景 | 走走停停、频繁正反转、负载不大、工作制低于50% |
| 品牌 | 雷赛 |

**步距角与相数：**

| 相数 | 步距角 | 脉冲数/圈 | 2倍细分 |
|------|--------|----------|---------|
| 2相 | 1.8° / 0.9° | 200 / 400 | 400 / 800 |
| 3相 | 1.5° / 0.75° | 240 / 480 | 480 / 960 |
| 4相 | 0.9° / 0.45° | 400 / 800 | 800 / 1600 |
| 5相 | 0.72° / 0.36° | — | — |

> ⚠️ **选型关键**：根据单位移动量A确定步距角。例如同步带模组，电机转一圈负载运动距离A=100mm，1.8°步距角意味着同步带前进0.5mm（100/200个脉冲一圈）。

**旋转力矩计算：**

- T = T(加速) + T(匀速)
- T(加速) = 惯量J × 角加速度β
- T(匀速) = F(外力) × R(半径) / η(效率)

**惯量比计算：**

- 含减速器：负载惯量 / (电机转子惯量 × 减速比i²)
- 不含减速器：负载惯量 / 电机转子惯量

**矩频曲线**：对照曲线图，转矩放2倍安全系数选型。

**开环 vs 闭环步进：**

| 类型 | 丢步处理 | 静止状态 | 适用速度 |
|------|---------|---------|---------|
| 开环步进 | 无反馈 | 绝对静止 | 600转以内 |
| 闭环步进（混合伺服） | 编码器反馈，偏离位置插补或报警 | 高频低幅度抖动 | 更高 |

#### 直驱电机

**DD马达（旋转直驱）：**

| 参数项 | 内容 |
|-------|------|
| 运行模式 | 梯形 / 三角形 |
| 结构特点 | 外圈旋转（大惯量）/ 内圈旋转（轻载低惯量） |
| 关键特性 | 高精度、大扭矩、低转速 |
| 转速范围 | 小型号2000转，大型号720转 |
| 本质 | 定制化特殊伺服电机 |

**直线电机（DDL）：**

| 类型 | 铁芯 | 关键特性 | 典型应用 |
|------|------|---------|---------|
| 平板型 | 有铁芯 | 高速 | 高速贴片机 |
| U型 | 无铁芯 | 稳定性好 | 激光扫描 / 视觉检测 / 点胶 |

- 运行模式：梯形 / 三角形（匀速运行要求，距离长/点对点）
- 双动子直线电机：两个动子同时运动，需单独控制，动子上结构加防撞件
- 安装：动子和定子间距值0.8–1.2（查样册或问厂家）
- 长度理论上无限，实际取决于拖链，一般需要定制

**音圈电机**：精密短行程直线运动。

#### 伺服 vs 步进速查

| 对比项 | 伺服电机 | 步进电机 |
|--------|---------|---------|
| 控制方式 | 闭环 | 开环（闭环可选） |
| 低速表现 | 不抖动不爬行 | 低速震动 |
| 高速力矩 | 额定转速下恒力矩 | 高速力矩骤减 |
| 过载能力 | 最大转矩3倍额定 | 无过载能力 |
| 价格 | 高 | 低 |
| 适用场景 | 高精度、高速、高响应 | 走走停停、频繁正反转、负载不大 |

|------|------|

#### 3. 减速器

| 高精度 | RV（行星摆线针轮） | — | — | 结构复杂、体积大、承载力强 |

> ⚠️ **人形机器人减速器应用参考**：胯部关节用RV，手臂关节用行星，腕部肘部关节用谐波。

#### 选型要素

- 基本参数：输出转速、输出转矩、功率、安装形式（机架/法兰/平面）、外壳尺寸、输出轴属性（轴径/轴长/键尺寸）
- 三大安全系数相乘：温度系数 × 工作机系数 × 启动系数 → k最终安全系数
- 减速器额定功率最好比电机功率大
- P(减速机功率) = T(额定允许力矩) × n(额定允许转速) / 9550

**选型前提（至少满足其一）：**
1. 已知电机参数 → 减速机功率 = 电机功率 × k
2. 已知输出轴参数

**选型顺序**：丝杆、电机预选（根据负载）→ 验证 → 根据电机选择减速机

#### 减速器的正向/负向影响

| 影响 | 说明 |
|------|------|
| 正向 | 更高发挥电机效率（伺服额定3000，实际需求一般1000）；大力矩需求下节约成本 |
| 中性 | 功率会有基于效率的折损；小功率小速比可用同步带代替；一般电机和减速机一起购买 |
| 负向 | 一般都有侧隙影响精度（高精度型号除外）；自重增加 |

#### 2. 气源处理流程

完整处理链路（按顺序）：

| 步骤 | 设备 | 作用 |
|------|------|------|
| 1 | 空压机 | 压缩空气（温度升高） |
| 2 | 冷凝器 | 降温 |
| 3 | 储气罐 | 储存气体、保压 |
| 4 | 空气过滤器 | 除油、除水、除尘 |
| 5 | 手滑阀 | 控制通断气 |
| 6 | 三联件 / 二联件 | 油水分离 + 调压阀 + 油雾器（三联件）；油水分离和调压阀一体（二联件） |

> ⚠️ **实践提示**：大型设备用三联件，一般用二联件+手滑阀（接进气端，控制通断气），二联件出气端接汇流板。调压阀有精密型+精密过滤器（对气体有严格要求工况），非标设备一般过滤精度40μm（查气缸样册）。

#### 7. 真空系统

#### 自制真空腔体

结构：下腔体（一个或多个空腔，可加密封槽）+ 上盖板（多个通孔）+ O型密封条/密封胶垫/密封胶 + 螺丝锁紧（最好分区）。

## 六、传动
### 1. 丝杆传动

#### 1. 丝杆类别

| 类型 | 摩擦方式 | 自锁性 | 传动效率 | 典型应用 |
|------|---------|--------|---------|---------|
| 梯形丝杆 | 滑动摩擦 | 可自锁 | 0.6–0.8 | 手动调节、低成本场合 |
| 滚珠丝杆 | 滚动摩擦 | 无自锁，传动可逆 | 0.95以上 | 非标最常用，高精度传动 |
| 行星滚柱丝杆 | 滚动摩擦 | 结合二者 | — | 超大输出力，应用于电缸 |

#### 2. 丝杆模组组成

完整模组包含：滚珠丝杆（或行星滚柱丝杆）+ 丝杆螺母 + 丝杆安装座 + 传感器3个（限位2个、原点1个）+ 电机 + 联轴器。

**安装座结构：**

| 端 | 组成 | 说明 |
|----|------|------|
| 固定座 | 锁紧螺母 + 定套2个 + 角接触球轴承2个 + 法兰挡盖 | 承受轴向力 |
| 支撑座 | 深沟球轴承 + 轴用卡簧1个 | 仅支撑 |

**螺母安装座**：开口Ω形方便安装拆卸，与螺母安装座孔采用大间隙；与工装治具（滑台面）连接做定位（定位销/腰形槽）。

#### 3. 丝杆模组产品

| 产品 | 配套电机 | 适用场景 |
|------|---------|---------|
| 电缸 | 伺服电机 | 高推力、力矩/速度/位置可控 |
| 滑台 | 伺服/步进 | 常规定位 |
| KK模组 | 伺服/步进 | CCD视觉系统、激光、高精度定位（优先选KK） |
| 丝杆电机 | 通常步进电机 | 紧凑结构 |
| 贯穿式丝杆电机 | 步进 | 丝杆贯穿电机来回移动 |

> ⚠️ **步进电机不能用于电缸**：高速力矩下降严重。长行程误差大时可加磁栅尺或光栅尺形成闭环控制。

#### 4. 安装方式

| 方式 | 占比 | 适用场景 |
|------|------|---------|
| 固定+支撑 | 80% | 适合高速，最常用 |
| 固定+浮动 | — | 垂直传动、短行程（150mm以内） |
| 固定+固定 | — | 大负载、低速场合 |

**固定端结构**：座子基体（轴承套件）/ 固定螺母 / 两个轴环。通常面对面安装，允许轴向误差；高精度场合背对背安装，悬臂结构采用背对背，刚性更足。

**支撑端结构**：深沟球轴承一个 + 卡簧一个。

#### 5. 丝杆尺寸计算

#### 细长比

细长比 = 丝杆传动有效行程 / 丝杆直径。长度和轴径的比值可用于快速选型（经验值），无需校核丝杆强度。普通选型查表：安装距离与轴向负荷 / 安装间距与转速。

| 品牌等级 | 细长比限制 |
|---------|-----------|
| 国产 | 40以内 |
| 进口 | 50以内 |
| 一线品牌 | 60以内 |

> ⚠️ **增加细长比方式**：加装辅助支撑（增加稳定性）；螺母旋转带动负载移动（利用丝杆运动可逆性）。正反丝杆（一正一反）用于同步夹紧松开动作。

#### 导程

丝杆螺纹距离，也称单位移动量。常用值：2、4、5、6、8、10、16、20、25、32、40。

#### 轴径

丝杆外径常用值：12、14、16、20、25、32、40、50、63。查表：负载和轴径的关系曲线。

#### 长度

- 丝杆总长 = 两端轴肩尺寸 + 螺纹长度
- 总长一般不超1.5m，过长导致转速变低（转速高会导致甩动）
- 螺纹长度 = 行程长度 + 螺母长度 + 预留余量

> ⚠️ 和厂家品牌丝杆质量参差不齐，选型时注意。

#### 6. 丝杆螺母

#### 循环方式

| 方式 | 说明 | 适用 |
|------|------|------|
| 内循环 | 滚珠始终和丝杆接触 | 结构紧凑，小型轻载 |
| 外循环（端盖/端面式） | 滚珠脱离丝杆接触面，通过插管或螺旋槽返回 | 应用广泛 |
| 外循环（插管式） | — | 大型重载 |
| 外循环（螺旋槽式） | — | — |

#### 螺母类型

| 类型 | 说明 |
|------|------|
| 预压型 | 双螺母型 / 单螺母型（变导程预压、大滚珠预压） |
| 球保持型 | — |
| 静音型 | — |
| 无预压 | — |

> ⚠️ **非标设备通常不需要预压工艺**，高精度设备需要考虑。

#### 7. 预压工艺

**预压方式**：错位预压 / 定压预压 / 双螺母预压 / 过盈预压（大珠子）。

**预压作用：**
- 提高精度：消除丝杆和螺母之间的间隙
- 增强稳定性：大负载减少晃动；无预压的丝杆螺母会因自身重量而掉落

| 方式 | 说明 |
|------|------|
| 联轴器直连 | 最常用 |
| 同步带连接 | 张紧一般需要电机轴固定座打腰孔，张紧时斜拉即可 |

### 2. 链传动

#### 1. 链条分类

| 类型 | 关键特性 | 典型应用 |

#### 2. 链条参数

**节距计算：**

| 标注方式 | 公式 | 举例 |
|---------|------|------|
| 链号（如08A） | p = 链号 × 25.4 / 16 | 08A → p = 12.7mm |
| 分号（如4分链） | p = 分号 × 25.4 / 8 | 4分 → p = 12.7mm |

> 节距：两根销子之间的距离。

#### 3. 链条选型

- 抗拉强度安全系数：国标8–12倍，品牌手册3–6倍
- 功率需求：链条承载功率 ＞ 电机输出功率 ＞ 负载需求功率

#### 4. 链轮

**分度圆直径**：d = p / sin(180°/z)，其中 d 为分度圆直径，p 为链条节距，z 为链轮齿数。

- 齿数推荐不少于17齿
- 包角120°以上

> ⚠️ **链最好是偶数链节 / 链轮最好是奇数齿数**，奇偶配合，均匀磨损。

#### 5. 辅助结构

| 部件 | 说明 |
|------|------|
| 耐磨条 | 材质超高分子聚乙烯 |
| 钣金支撑 | 只起支撑，不作承载 |
| 张紧机构 | 调中心距（主动轮从动轮距离调节） |
| 自动张紧 | 依靠重力 |
| 涨紧轮 | 加涨紧轮 |

#### 6. 接头

| 类型 | 条件 | 强度 |
|------|------|------|
| 全接头 | 链条节数偶数 | 正常（优先使用） |
| 半接头 | 链节数奇数 | 原来的0.8（尽量避免） |

### 3. 齿轮传动

#### 1. 传动形式

| 形式 | 齿轮类型 | 关键特性 |
|------|---------|---------|
| 平行轴传动 | 圆柱直齿轮、圆柱斜齿轮 | 斜齿轮啮合平稳，逐渐进入/脱离 |
| 交叉轴传动 | 锥齿轮/伞齿轮 | 输入轴与输出轴垂直或成任意角度且相交 |
| 交错轴传动 | 蜗轮蜗杆 | 传动比不高时不考虑自锁性 |
| 旋转→直线转换 | 齿轮齿条 | 齿条原则上无限拼接，受限于拖链长度 |

> 任意角度可用万向节代替锥齿轮。人字齿解决了斜齿轮的轴向力问题；斜齿圆柱齿需要推力轴承解决轴向力，也可成对使用达到人字齿效果。

#### 2. 齿轮基本参数

**正确啮合条件**：模数m相同、压力角α相等（标准齿轮α = 20°），一般是渐开线齿轮，互为质数均匀磨损。

#### 圆柱直齿轮

| 参数 | 公式 | 说明 |
|------|------|------|
| 标准中心距 a | a = m × (z1+z2) / 2 | 理论上无间隙 |
| 分度圆直径 D | D = m × z | 标准齿轮时齿厚 = 齿槽宽 |
| 齿距 p | p = π × m | 由模数确定齿距 |
| 齿顶高 ha | ha = m | 齿顶高系数ha* = 1 |
| 齿根高 hf | hf = (ha*+c*) × m | m≥1时c*=0.25；m<1时c*=0.35 |

> 模数m值越大，齿距越大，承载力越强，分度圆直径越大。

#### 圆柱斜齿轮

| 参数 | 公式 | 说明 |
|------|------|------|
| 标准中心距 a | a = m × (z1+z2) / 2 | 最好做中心距可调 |
| 分度圆直径 D | D = m × z / cosβ | β为螺旋角 |
| 齿顶高 ha | ha = m | — |
| 齿顶圆直径 Da | Da = D + 2m | — |

#### 3. 齿轮啮合

#### 侧隙（背隙）

| 消除方式 | 说明 |
|---------|------|
| 无侧隙齿轮 | 拉簧拉 / 锁付式错位齿轮 |
| 高精度齿轮 | 选择精度等级高的齿轮 |
| 可调中心距 | 结构做可调节中心距形式 |

#### 重合度

- 相同模数下，增加齿数 → 提高重合度
- 齿轮大小不变时，减小模数 = 增加齿数
- 重合度大 → 同时啮合齿数多 → 传动平稳、相对精度高

#### 互为质数

为均匀磨损，大小齿轮齿数互为质数（质数：只有1和它本身两个因数，如13、17、19）。

#### 4. 变位齿

**作用：**
- 结构需要改中心距（匹配中心距），其它条件不变
- 增加小齿轮强度 → 正变位；大齿轮磨损修复 → 负变位

| 形式 | 说明 |
|------|------|
| 正变位 | 刀具远离齿轮中心，远离距离 X×m（X为变位系数） |
| 负变位 | 刀具靠近齿轮中心，靠近距离 X×m |

> 分度圆相切是标准形式，相切基础上改变中心距，使插齿刀具远离为正变位，靠近为负变位。

#### 5. 齿数

- 避免根切现象：不小于17齿
- 12齿开始避免根切需采取变位

#### 6. 生成齿轮模型

**大工程师插件：**
- 齿宽 = 齿宽系数 × 分度圆直径（不需要手动考虑）
- 重合度自动生成，要求＞1（避免啮合不连续）
- 螺旋角：直齿轮为0，斜齿轮随意设定
- 校核：转速/功率/使用寿命（不影响齿轮生成）
- 生成齿轮模型可用于直接加工，但需手动验证模型尺寸（不建议直接给模型加工，防止出错）；若用于线割给参数可调模型（线割有齿轮模型库）

**凯元**：可生成齿轮、齿条、齿圈，没有强度校核。

### 4. 齿轮齿条传动

#### 1. 齿轮齿条类型

| 类型 | 配套齿轮 | 关键特性 | 适用场景 |
|------|---------|---------|---------|
| 直齿条 | 直齿圆柱齿 | 加工简单可线割，啮入啮出冲击大、噪音大 | 低速轻载 |
| 斜齿条 | 斜齿圆柱齿 | 啮入啮出同时存在，运行更平稳 | 高速运行、重负载 |

> 通常供应商现货齿条长度1米或2米。齿条原则上无限拼接，实际受限于拖链长度。

#### 2. 齿条拼接方式

用一小段齿条与拼接两齿条做啮合，再装螺丝。

#### 3. 齿轮齿条安装距离

A = h + [(m × z) / 2] + x × m

其中：A为齿条底面到齿轮中心距离，h为齿条啮合高度，m为模数，x为变位系数，z为齿数。

#### 4. 润滑方式

加毛毡轮，毛毡轮孔中心要有注油泵给注油。

| 类型 | 安装位置 | 说明 |

| 惰轮（带齿） | 松边内侧或外侧 | — |

## 七、导向
### 1. 直线导轨 + 滑块

#### 滑块

- 力矩方向：俯仰力矩（y向）、摆动力矩（x向）、回转力矩（z向）
- 侧面多个螺丝孔：固定（通孔和导轨固定）/ 安装 / 预压 / 多滑块并联

#### 导轨

**拼接方式**：多段导轨拼接可要求供应商做好无缝处理（即便自己做线割也不能保证无缝衔接）。

**定位方式：**

| 方式 | 说明 | 设计要点 |
|------|------|---------|
| 槽定位 | 最常用 | 非通槽时长度方向加大防放不进；边角处打工艺孔；槽宽一边公差0.05–0.1靠边，另一边加宽0.5–1mm靠调；深度2mm |
| 销钉定位 | 一边两个销钉定位，一边可调无需定位 | 销子孔配合不要过盈；朝下销钉用硬物敲击孔侧面起毛刺防掉落 |
| 螺钉/压板/滚柱压紧 | 导轨侧面用螺丝顶 | 要求高精度高刚性的场合 |

**润滑方式**：加注油泵 + 分油器，连接滑块上油嘴。导轨螺丝孔有防尘盖。

**安装方式**：导轨固定+滑块移动，或滑块固定+导轨移动（根据应用场景和空间）。

**预压**：重载需要预压，调节滑块和导轨间隙。

**摩擦系数**：由于安装不平行或预压造成摩擦增大，给摩擦系数0.2。

#### 导轨防护罩

风琴罩（需考虑行程和压缩量）。

### 2. 光轴 + 直线轴承 / 滚珠花键（滚动摩擦）

| 项目 | 说明 |
|------|------|
| 光轴 | 表面淬火 + 镀硬铬 |
| 直径选择 | 和气缸轴一般大或略大（经验） |
| 设计注意 | 光轴上铣柄位或孔位需避开轴承滑动范围 |
| 滚珠花键 | 可配合直线轴承/无油衬套，对角使用（高精度场景） |
| 安装不平行时 | 计算按0.1–0.15摩擦系数 |

> ⚠️ 直线轴承是直线运动，无油衬套可直线+旋转。直线轴承外径与安装板孔采用大间隙。

### 3. 光轴 + 无油衬套（滑动摩擦）

| 衬套材料 | 光轴要求 | 适用 |
|---------|---------|------|
| 黄铜+石墨 | 调质+镀硬铬 | — |
| 青铜 | 调质+镀硬铬 | — |
| 复合树脂型/赛钢/尼龙 | 镀铬/铝轴 | — |

**应用场景：**
- 重载或小孔：衬套外径与孔有点过盈，侧面用机米螺丝顶住（最好做沉头）
- 长导杆/长行程追求稳定性：上下长管（末端开止口放铜套）+ 中间法兰固定

## 八、控制元件与传感器
### 1. 传感器与编码器

#### 1. 接触式传感器

| 类型 | 说明 | 典型应用 |
|------|------|---------|
| 限位开关 | 机械碰撞触发 | 锯床升至上方碰到限位停止 |
| 微动开关 | 小行程触发 | — |
| 接触式位移传感器 | 对刀仪、基恩士GT式（精度0.1μm–1μm） | 高精度位移检测 |
| 压力传感器 | 电缸配；气液增压缸可配 | 力控制 |
| 热电偶 | 温度传感器 | 测试环境温度 |
| 流量计 | 电气工程师和工艺工程师一起搞 | 流量检测 |

#### 2. 非接触式传感器

#### 接近开关

| 类型 | 检测对象 | 头型 | 安装方式 | 说明 |
|------|---------|------|---------|------|
| 电感式 | 金属 | 凸头型（非屏蔽） | 露出一截凸头（非埋入式） | 检测距离远，检测输送机治具/产品到位 |
| 电感式 | 金属 | 平头型（屏蔽） | 埋入孔中顶面平齐 | 检测距离近，准确度更高，检测模组/气缸/滑块到位 |
| 电容式 | 金属和非金属 | 凸头/平头 | — | 能不用尽量不用（灰尘也会被检测），一般平头居多 |

> ⚠️ 接近开关分PNP和NPN两种型号，选型取决于PLC是PNP还是NPN。

#### 磁性开关（干簧管）

检测带磁性对象。气缸活塞上带永磁磁环，检测精度不高，可在PLC设置加信号延时。

#### 光学传感器

| 类型 | 原理 | 关键特性 |
|------|------|---------|
| 漫反射型 | 自发自收（单头，红光/绿光/白光） | 简单 |
| 镜面反射型 | 带反光板 | 检测精度更高 |
| 对射型 | 成对使用 | 检测可靠 |
| 槽型光电 | — | 限位及检测原点位置（3个）；感应钣金宽度5–6mm，做腰形孔上下可调 |
| 光纤传感器 | 光轴型/螺纹型 | 安装空间小；对射型/反射型 |
| 激光传感器 | — | 检测距离是重点，输出模拟量 |
| 安全光栅 | — | 检测体：手指/手掌/手臂 |

#### 红外温度传感器

有一定距离测温。

#### 3. 视觉系统（CCD）

> ⚠️ 选型由视觉工程师出方案，机械工程师主要考虑安装。

#### 功能

| 功能 | 说明 |
|------|------|
| 表面检测（常用） | 划痕等缺陷、打标是否完整 |
| 轮廓检测（常用） | 检测缺陷、检测尺寸（无接触式，代替测量） |
| 位置检测 | 零散小零件+蜘蛛机械手高速分选 |
| 颜色及光泽检测 | 必须彩色相机 |
| 零件定位 | — |

#### 组成

| 组件 | 类型 | 说明 |
|------|------|------|
| 光源 | 面光源/背光源/环形/条形/同轴 | 相当于照明（厂商：OPT/LOTS） |
| 相机 | 全局（动态检测）/ 卷帘（静态检测） | 2D面阵/线扫/3D/炮筒（远心镜头） |
| 镜头 | FA镜头 / 远心镜头 | 靶面尺寸一般是产品尺寸的1.2–2倍 |
| 工控机 | 工业电脑（含显卡、处理器） | — |

**对位形式**：Mark点定位（靶标）/ 抓边定位，通常1/2/4/5个相机（视野有限）。

**安装要点**：
- 白色背光板（尼龙/赛钢），周围组件氧化黑（避免反光）
- 相机位置做上下可调，光源中心尽量与夹具中心对齐
- 可用手动丝杆滑台/手动位移台
- 刚性/可调：连杆/抱箍、支架腰形槽推拉螺丝

#### UVW对位平台（搭配纠偏）

- 组成：交叉滚子轴承（可旋转运动，角度范围很小）+ 控制电机+丝杆传动（X/Y轴）
- 导轨两种结构：十字交叉导轨滑块（较老、较高）/ 交叉导轨滑台（较新、较低）
- 应用：粗定位（机械定位）→ 纠偏
  - 预纠偏（上料前）：CCD检测 → 上料机构调整 → 粗略对准UVW平台 → 放上物料
  - 精纠偏（上料后）：CCD复检 → UVW平台调整 → 完成定位

#### 4. 编码器

将机械运动物理量转化为电信号反馈给PLC。

#### 旋转编码器

| 类型 | 断电处理 | 原点 | 传感器配置 |
|------|---------|------|-----------|
| 绝对值编码器 | 自带原点（加电池或直接读数式） | 不需要原点传感器 | 只需两个限位 |
| 增量式编码器 | 断电后需复位 | 需要原点传感器 | 两个限位 + 一个原点（原点与一个限位挨着，做可调结构，每次回原点朝一个方向） |

> 也分绝对式（无需归零）和增量式（老旧驱动器/上位机无法兼容绝对式编码器时用）。

#### 直线编码器

| 类型 | 精度 | 应用 |
|------|------|------|
| 光栅尺（金属式） | 5μm | 数控机床传动位置检测 |
| 光栅尺（塑料式） | 低于金属式 | 性价比高 |
| 磁栅尺 | 5μm–10μm | 数显游标卡尺、设备实际位移检测 |

**传感器作用汇总**：限位 / 定位 / 原点 / 有无 / 检测。

> ⚠️ 待机位就是初始位置。若传感器坏了有可能就撞机了，电气工程师调试时也容易撞机。

## 九、功能元件
### 1. 联轴器

**作用**：①连接传动 ②消除轴间偏差 ③过载保护。

| 类型 | 传动滞后 | 适用场景 |
|------|---------|---------|
| 沟槽型 | 无 | 小力矩、小转速、高精度 |
| 膜片式 | 无 | 大力矩、高转速（伺服电机标配，非标最普遍） |
| 梅花型 | 有 | 普通电机（长时间匀速运行） |
| 刚性 | — | 简单连接两根轴 |

**力矩匹配：**
- 需要电机过载能力：联轴器额定扭矩匹配电机峰值力矩（带安全系数），电机无论如何不能把联轴器拧断
- 需要过载保护：联轴器最大扭矩匹配电机保护力矩值，超限则断联轴器或打滑

**安装**：与轴连接不要越界（重要），两轴中间预留空区间。电机输出轴与减速器输入轴采用联轴器抱死（减速器侧孔有顶丝可锁死联轴器）。

### 2. 拖链选型

#### 最小转弯半径

| 管线类型 | 倍数 |
|---------|------|
| 电缆线（国标） | 8–10倍直径（无脑10倍） |
| 电缆线（进口） | 6倍直径 |
| 气管 | 10–12倍 |
| 液压管 | 12倍 |
| 水管 | 10–12倍 |

#### 口径大小（线径总和）

| 设备 | 线径 |
|------|------|
| 电机（电源线/刹车线/编码器线） | 全部8mm |
| CCD（网线/电源线/光源线） | 6mm / 8mm / 5mm |
| 传感器 | 3mm |
| 气缸 | 一个进气管+一个排气管；多个气缸选汇流排，拖链一根气管通入即可 |

**长度**：一般建议铺满，批量精确计算（查样册）。通常预留30%空间，线与线隔开用拖链隔板。

**链节数** = 总长 / 链节距。

**分隔**：电气分隔 / 强弱分隔（防止干扰）。

> ⚠️ 拖链口附近打穿气孔，过长会下垂，下面做不锈钢钣金支撑。

### 3. 接头类

| 类型 | 说明 |
|------|------|
| 气动旋转接头 | 内置轴承，Rc1/8 = 1分外螺纹，防止单个气管轴向拧 |
| 气滑环 | 内孔套在轴上顶丝固定，侧面开孔，防止多气管缠绕 |
| 气电滑环 | 既有气又有电的场景 |
| 电滑环 | 电动旋转接头 |
| 摆动接头 | I型 / Y型 / 鱼眼 / 浮动接头 |

**自制真空气滑环**：两个轴承 + 两个密封圈 + 挡圈 + 轴（内部气孔，侧面气孔）。要求不高用O型圈，要求高用格来圈。

#### 风扇

| 类型 | 作用 |
|------|------|
| 轴流风扇 | 散热，有时用于内部气体循环（一抽一吹） |
| 横流风机 | 冷却 |

| 负压风机 | 负压 |

用于门板等需要支撑力的场合。

### 5. 限位 / 防撞 / 防脱落

| 类型 | 说明 |
|------|------|
| 限位块（PU聚氨酯） | 机械限位 |
| 油压缓冲器 | 能量 = ½mv² + F×L；F(N) = p(MPa) × π × r(mm)² |
| 防撞装置 | 油压缓冲器 + 防撞螺丝（防御性设计），细牙螺纹连接 |
| 优力胶 | 防撞缓冲 |
| 安装防坠 | 优力胶（如竖直导轨滑块安装防冲出跑道） |

### 6. 电磁夹具

| 类型 | 关键特性 | 注意事项 |
|------|---------|---------|
| 电磁吸盘 | 通电产生吸力，吸附力大 | 长时间通电高温致磁力减退（需水冷）；卫生不好搞（推荐无尘空间）；自重很重；最高不要用于垂直工况（脱磁下坠危险） |
| 永磁吸盘 | 通电磁力消失，断电磁力恢复 | — |

- 显示屏常规17寸/21寸，软件或视觉工程师选型，机械负责开口尺寸和安装
- 显示屏下方开关常规5个（问电气），开孔尺寸一般22.5
- 触摸屏：气动控制/电动控制

### 8. 张力控制

#### 制动器分类

| 类型 | 说明 |
|------|------|
| 阻尼（阻尼器） | 基础制动 |
| 导轨钳制器 | 工装换型/刹车保护/增加刚性 |
| 电磁制动器 | — |
| 磁粉制动器 | 力矩可调（5%–100%），可做张力控制闭环 |

**导轨钳制器应用场景：**
- 工装换型：多位置换型用刻度尺+导轨钳制器，或腰形孔+刻度尺，或微动平台
- 刹车保护：防止联轴器/丝杆失效（常闭型，断气断电时刹车抱死）
- 增加刚性：平衡/固定/配重

**摩擦力计算（压机为例）：**
- F(静) = F(夹) × μ（摩擦系数）
- 不打滑条件：F(静) ≥ F(压) + MG

**常开/常闭/刹车型**：气压锁紧刹车力一般5kg，液压锁紧一般30kg。

> ⚠️ 不作为滑块运动停止过程中频繁使用钳制器（会大大降低使用寿命），只作为断气断电保护方式。

**导轨钳制器选型步骤**：①确定动能类型（手动/气动/电动/液压）②匹配导轨尺寸 ③确认保持力 ④确认型号和安装尺寸。

#### 磁粉制动器选型

- 负载最大力矩 ＜ 最大力矩80%
- 发热功率 ＜ 散热功率（发热功率 P = F(张力) × V(线速度)）
- 最小转速 ＞ 手册最小转速
- 安装搭配：卡座 + 气涨轴 + 张力传感器 + 张力控制器

#### 离合器

状态：断开动力 / 完全连接 / 半连接（力矩可调）。

**磁粉离合器选型**：
- 发热功率 P = P1-P2 = T × (N1-N2) / 9550
- 最小转速差 ＞ 手册最小转速差

**材料张力**：总张力 = 宽度 × 厚度 × 材料张力系数。

## 十、标准件
### 1. 螺栓 / 螺纹

#### 粗牙 vs 细牙

| 类型 | 特性 | 适用 |
|------|------|------|
| 粗牙（标准螺纹） | 承载力强、受冲击力强、容易松动 | 常规紧固 |
| 细牙 | 气密性好、自锁性较高、容易滑丝 | 薄壁零件、密封螺丝、调节机构 |

#### 螺纹配合

通常外螺纹6级精度，内孔7级精度。螺纹公差6h/6H区别于圆柱/孔公差h6/H6。

#### 螺栓等级

| 等级 | 含义 |
|------|------|
| 8.8 | 抗拉强度800MPa，屈服强度640MPa |
| 10.9 / 12.9 | 更高等级 |

#### 螺栓强度校核

**三种连接类型：**

| 连接类型 | 受力 | 说明 |
|---------|------|------|
| 松连接 | 轴向力 | 计算全部负载需要至少多大螺丝 |
| 紧连接 | 密封性要求 | 管道、法兰 |
| 绞制孔连接 | 横向力（剪切力） | 预紧力F = 屈服强度×70% |

**旋转紧固（联轴器为例）**：F = T / L（T力矩，L螺丝距旋转中心距离）。

#### 最小啮合长度

| 材料 | 螺纹大径的倍数 |
|------|--------------|
| 钢 | 1.0–1.2 |
| 铸铁 | 1.5 |
| 铝 | 1.5–2 |
| 非金属 | 2 |

螺栓螺纹部分超出螺母长度2–3个牙。

#### 防松措施

| 序号 | 方式 |
|------|------|
| 1 | 弹簧垫圈（常用） |
| 2 | 对顶螺母 |
| 3 | 定制螺母+顶丝 |
| 4 | 防松螺母（过盈手段） |
| 5 | 自锁垫圈（齿形垫圈） |
| 6 | 螺纹胶（预涂型用于密封/气动件；厌氧胶锁紧20秒见效） |

#### 螺栓类型

| 类型 | 说明 |
|------|------|
| 普通螺栓 | 内六角 / 外六角 |
| 绞制孔螺栓 | 过渡配合JS或K，光轴部分等同于销钉，配螺母使用（基轴制） |
| 等高螺栓（塞打螺丝） | 结构同绞制孔螺栓，强调等高 |
| 螺钉 | 平头（锥孔）/ 半圆头（直孔） |
| 顶丝 | 固定轴相对运动 / 便于拆卸 / 调整间隙精度 |

#### 特殊螺栓

| 特殊要求 | 推荐材料 |
|---------|---------|
| 耐药性 | 哈氏合金 / 钛 / 316 / PEEK / 特氟龙 |
| 低漏气性 | PEEK / 特氟龙（密封螺丝、真空堵头） |
| 耐热性 | 316 / 304 / 陶瓷螺栓（1500°C） |

### 2. 弹簧

| 类型 | 力学公式 | 说明 |
|------|---------|------|
| 拉伸弹簧 | F = 初始拉力 + (弹簧常数 × 位移量) | 初始状态不可压缩 |
| 压缩弹簧 | F = 弹簧常数 × 位移量 | 圆形/矩形截面 |
| 扭簧 | T = 弹簧常数 × 扭转角度；F = T / L(力臂) | 左旋/右旋；弹簧常数单位N·mm/deg |
| 恒定弹簧（发条弹簧） | 力恒定 | 一定行程范围内力恒定 |

**弹簧常数**（N/mm）：长度每变化1mm，增加1N的力。**初始张力**：拉动弹簧的最小拉力，低于此力无形变。

**选型步骤**：①弹簧种类 ②变化行程范围 ③安装空间（内外径/线径/长度）④需求力范围（初始力/最大力）⑤校核位移范围及对应输出力。

> 样品收藏：找厂家要，怡合达插件里可申请。要求较高时拿样品做试验。
