# 同步带选型

## 选型步骤
1. 确定设计功率：Pd = P × K（K 为工况系数）
2. 选择带型（参考选型图）
3. 确定带轮齿数和节径
4. 计算带长和中心距
5. 校核带速和张力

## 常用带型
| 带型 | 节距 (mm) | 适用功率 |
| :--- | :---: | :--- |
| XL | 5.08 | 小功率 < 0.5kW |
| L | 9.525 | 中功率 0.5~2kW |
| H | 12.7 | 大功率 > 2kW |
| XH | 22.225 | 重载 |

## 基本原则
- 中心距 > 3m 时 **必须加张紧检测**
- 带速 ≤ 30m/s
- 小带轮齿数 ≥ 12（避免弯曲疲劳）
