# 气缸力计算

## 基本公式

### 推力
```
F_push = P × A_push = P × π × D² / 4
```

### 拉力
```
F_pull = P × A_pull = P × π × (D² - d²) / 4
```

| 符号 | 含义 | 单位 |
| :--- | :--- | :--- |
| F | 理论出力 | N |
| P | 使用气压 | MPa |
| D | 缸径 | mm |
| d | 活塞杆径 | mm |

## 实际可用力
```
F_actual = F_theory / S
```
S ≥ 1.5（安全系数）

## 快速估算
- 0.5MPa 时，推力 ≈ 缸径² × 0.8
- 例：φ40 缸 ≈ 40² × 0.8 = 1280N（理论值）
