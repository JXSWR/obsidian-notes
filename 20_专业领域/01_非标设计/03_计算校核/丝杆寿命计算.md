# 丝杆寿命计算

## 基本公式
```
L = (C / P)³ × 10⁶
```

| 符号 | 含义 | 单位 |
| :--- | :--- | :--- |
| L | 额定寿命 | 转数 |
| C | 基本动额定载荷 | N |
| P | 轴向负载 | N |

## 转换为运行时间
```
L_h = L / (60 × n)
```

| 符号 | 含义 | 单位 |
| :--- | :--- | :--- |
| L_h | 寿命 | h |
| n | 平均转速 | rpm |

## 多工况寿命计算
当负载和转速变化时：
```
1/L_total = Σ (t_i / L_i)
```

## 校核要求
- 寿命 ≥ 5000h（通用）
- 或按客户指定寿命
