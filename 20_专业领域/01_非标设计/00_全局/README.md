# 🧭 非标设计知识库 — 全景导览

> 讲清这套知识库**为什么这么分、各部分怎么互相关联渗透**。
> 检索用 [[20_专业领域/01_非标设计/00_全局/索引|总索引]]；**想看懂整体结构读本文件**。

## 一句话

把 13 年非标经验拆进 6+ 个目录，靠「**设计时正向取用、做完后反向沉淀**」两条路串成闭环。**每个目录都不是孤岛**——同一份知识按用途拆散到各处，用链接织成网：机构档案里挂着选型与计算，选型页链着校核公式，案例提炼出的卡片反哺台账与机构档案。

## 全景 — 两条路

```
【设计新设备 · 正向取用】 铁律/流程(04) → 机构(01) → 选型(02) → 计算校核(03) → 材料工艺(04) → 参考案例(05.1) → 禁忌/碎片(06) → 可复用卡(07)
                                        ▲                                    ▲
                                        └──────── 互为上下游，双向可跳 ────────┘

【沉淀知识 · 反向生产】 项目过程(50) → 自建案例(05.2) ─┐
                                          课程案例(05.1) ─┤→ 提炼 → 07_可复用卡(成品)
                                                            │        ↕ 未成型先落
                                           真实项目验证(50)← 台账(04) ← 06_经验碎片(毛坯)
```

正向：做设备时一路**查**下去；反向：做完把新经验**提**出来回填，让下次正向更快。

## 目录角色与交叉渗透

| 目录 | 角色 | 与谁互相渗透 |
| :--- | :--- | :--- |
| `01_机构库/` | 机构档案（结构/组成/功能/场景） | 档案里的部件链 `02` 选型；校核链 `03` 计算；场景链 `05` 案例、`04` 布局大文档 |
| `02_选型库/` | 元件选型（标准件 9 类 + 通用件分类） | 每类选型页链 `03` 对应计算（气缸力/丝杆寿命/同步带/电机模组）；特殊工况反查 `07` 卡（如恶劣环境选型） |
| `03_计算校核/` | 单页计算/校核公式 | 被 `01` 档案、`02` 选型页、`04` 大文档反链——选型必须落到计算 |
| `04_查询库/` | 厚资料：设计导图、选型书、材料工艺、流程铁律、台账模板 | **母本库**：`非标设备结构及选型` 是元件参数总源；`机构作业台账` 承接 `07` 卡回填；`铁律/流程` 是每次设计的起点 |
| `05.1_参考案例库/` | 课程案例（原料矿） | 提炼产物 → `07` 卡；案例里的机构/选型做法链 `01`/`02` 印证 |
| `05.2_自建案例库/` | 本人项目成品案例 | 过程来自 `50_项目实践`；「我做过」的经验是 `07` 卡 **A 级素材唯一来源** |
| `06_经验碎片/` | 未成型的坑与观察（毛坯） | 提炼成型 → `07` 卡；新项目避坑直接查 `禁忌索引` |
| `07_可复用卡/` | 提炼成品（什么工况选什么形态） | 只**链接不复制**元件参数（去 `04` 母本），避免内容漂移；素材来自 `05`/`06` |

## 交叉渗透的实例

- **丝杆模组**：档案在 `01` → 支撑轴承去 `02_标准件` → 寿命校核去 `03` 丝杆寿命计算 → 电机匹配去 `04` 电机模组选型 → 场景对比去 `05` 案例里的长行程机构
- **真空吸附搬运卡**（07）← 自建案例 001/003 提炼（05.2）←→ 台账登记（04）→ 真实项目验证（50）
- **恶劣环境选型卡**（07）→ 触发 `02` 传感器/电机选型时先看环境 → 结论回写 `06` 碎片

## 知识与目录的关系

> 同一份知识会在多处出现，**但每处只留一种视角**：
> 元件参数 → 只存 `04` 母本；选型流程 → 只存 `02` 页；经验判断 → 只存 `07` 卡。
> 其它地方一律链接、不复制——复制就会漂移，两处迟早不一致。
> （唯一例外：`常用材料及表面处理工艺` 等整册资料整体归 `04`，不拆散。）
