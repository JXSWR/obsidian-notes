# 可复用卡模板

> **用途**：从案例（05.1 参考 / 05.2 自建）提炼可复用结构时套用。
> **三项必填**：`来源等级` / `状态` / `边界` —— 缺一不可。
> 卡只记「什么工况选什么形态、怎么避坑」，元件参数一律链接到选型/公式库，**不复制**，避免两处漂移。

```markdown
# 【卡名：工况 → 形态，如「真空吸附搬运」】

## 适用工况
【填：什么条件下查这张卡；明确不适用的情况（边界）】

## 形态对比
| 形态 | 结构要点 | 适用 | 不适用 / 坑 |
| :--- | :--- | :--- | :--- |
| 【形态1】 | 【填】 | 【填】 | 【填】 |
【填：2~5 种形态横向对比，这是卡的核心价值】

## 避坑 / 禁忌
- 【填：现场踩过的坑，一条一坑，宁可短不要空】

## 来源
- **来源等级**：A（本人亲历）/ B（课程案例）/ C（推算）——【填等级与出处案例】
- **状态**：待验证 / 已提炼 / 待 A 级验证 ——【填当前状态】
- **边界**：已验证的工况范围 + 未验证的假设
- 验证场：【填：哪个自建案例是它的 A 级验证场】

## 相关
- 提炼原料 → 【案例 03 可复用提取 链接】
- 元件参数 → 【标准件/计算 链接，不复制内容】
```

## 等级与闭环
- **A 级素材唯一来源**：05.2 自建案例（有「我做过」背书）
- **B 级素材**：05.1 课程案例（只知形态，无坑）
- **闭环**：案例 → 碎片（06）→ 卡（07）→ 回填 [[机构作业台账]] → 真实项目验证 → 升 A 级
- 卡建成后回填「00_全局/索引.md」07 节清单并挂链接
