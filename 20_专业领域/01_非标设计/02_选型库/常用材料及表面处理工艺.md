| 尼龙（PA66）                | 耐磨、自润滑                   | 导向耐磨条 / 耐磨块        |

- **优力胶（PU）**：缓冲防撞，邵氏硬度 80–90 度偏硬；可包胶；消音保温（PU 发泡）
- **橡胶**：密封圈
- **硅胶**：密封圈（无毒）

### 3. 其他

- **电木（PF）**：做治具较多，V 形结构治具可自定心且兼容不同尺寸，可攻牙锁螺丝
- 玻纤
- PE
- **PP**：耐腐蚀、环保
- PVC

## 四、热处理

| 工序           | 目的 / 效果                                  |
| -------------- | -------------------------------------------- |
| **退火**       | 降低材料硬度；消除应力（焊接后、粗加工后）   |
| **正火**       | 细化组织，提高综合性能（韧性、切削性能）     |
| **淬火**       | 提高硬度                                     |
| **回火**       | 消除淬火应力、降低硬度                       |

**回火细分：**

- 淬火 + 低温回火 — 保持硬度、降低脆性
- 淬火 + 中温回火 — 提高弹性、韧性
- 淬火 + 高温回火（调质） — 提高综合强度与韧性

**时效处理：**

- 人工时效：人工干预消除应力（振动）
- 自然时效：放置在自然环境

## 五、表面处理

### 钢制机加件

- **镀层**：镀锌（白锌、彩锌）/ 镀镍 / 镀铬 / 镀金
- **发黑 / 发蓝**：润滑性好，防腐蚀及耐磨性一般
- **喷砂**
- **喷涂铁氟龙**：润滑性、不沾性

### 钣金件 / 机架

- **喷漆 / 烤漆**（指定颜色，按公司规定）/ **喷塑**
  - 机架技术要求：未注尺寸按照 3D 执行
- **方通**：烤漆–喷电镀白（常用，不易生锈）

### 铝合金件

- **阳极氧化**：本色 / 彩色 / 氧化黑（哑光 / 亮光）
- **硬质阳极**
- **喷砂 + 阳极氧化**：比较美观，通常合并处理
- **钝化 / 铬酸盐氧化 / 磷化**

> ⚠️ **注意**：阳极氧化后不导电，无法线切割。

## 六、实用备注

- 加工完成后涂防锈油为常规防护
- 安装面涂清漆防锈，出工程图时标注
- 优质碳素钢品质等级按硫磷含量区分
