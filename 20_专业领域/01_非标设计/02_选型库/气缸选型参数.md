# 气缸选型参数

## 选型步骤
1. 计算所需推力/拉力
2. 确定缸径（参考下表）
3. 确认行程
4. 确认安装方式
5. 确认缓冲方式

## 缸径与出力对照（SMC CG 系列，0.5MPa）

| 缸径 (mm) | 理论推力 (N) | 理论拉力 (N) |
| :---: | :---: | :---: |
| 20 | 157 | 141 |
| 25 | 245 | 221 |
| 32 | 402 | 362 |
| 40 | 628 | 565 |
| 50 | 981 | 883 |
| 63 | 1558 | 1402 |
| 80 | 2513 | 2262 |
| 100 | 3927 | 3534 |

## 安全系数
- 实际可用力 = 理论力 / 安全系数 ≥ 1.5
