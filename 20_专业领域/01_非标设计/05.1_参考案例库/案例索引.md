### 03 与 04 的分工

| | 03 可复用提取 | 04 知识点汇总 |
| :--- | :--- | :--- |
| 装什么 | **可迁移的判断规则** —— 换了项目还成立 | **这台设备的具体知识** —— 机构、设计要点、实测参数 |
| 回答什么 | 下次能抄什么规则 | 这台设备里有什么 |
| 案例专属数字 | ❌ 不放（抄参数误导下个项目） | ✅ 放（本来就是这个案例的参数） |
| 产物去向 | → `07_可复用卡/`，见 可复用卡索引 | 留在本案例 |

## 案例目录标准结构

```
00N_项目名/
├── 参考案例NNN-01项目简介.md    ← 需求 + 方案 + 决策理由
├── 参考案例NNN-02案例卡片.md    ← 目录页：一页看清有什么
├── 参考案例NNN-03可复用提取.md  ← 什么值得抄 → 链接到 07_可复用卡/
└── 参考案例NNN-04知识点汇总.md  ← 机构清单 + 设计要点 + 选型参数 + 实测 BOM
```

> ⚠️ 原「模型说明 / 选型计算书 / BOM清单」三类已于 2026-09-04 **合并为 04知识点汇总**。
> 合并前先做内容提炼，无实质内容的空壳文件（纯 TODO）直接删除。

**外置部分（不在 vault 内，见 [[00_案例总览]]）：**

```
E:\模型文档\案例机构库\项目案例\案例NNN_项目名\
├── 项目3D文档/             ← SolidWorks 源（sldprt/sldasm/slddrw/step/dwg）
└── 项目输出文件/           ← 方案 PPT/PDF/脑图/规格书/作业指导书
```

## 新增案例流程

1. 建目录 `00N_项目名/`
2. 复制 [[参考案例解剖模板]]，按 `参考案例NNN-0X类型` 命名生成 4 篇
3. 大文件（3D/PDF/PPT）放 E 盘对应目录，md 里写绝对路径
4. 回填本页「四件套一览表」与 [[00_案例总览]]

> ⚠️ 新建时**不要加复盘笔记章节**。参考案例永远填不出复盘，加了只会制造 TODO 欠债。
