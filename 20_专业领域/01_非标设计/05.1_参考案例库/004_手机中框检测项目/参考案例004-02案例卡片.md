# 案例卡片 · 14期 手机中框检测项目

- **期数**：第 14 期
- **行业**：3C / 视觉检测
- **产品对象**：手机中框（检测上料机 + 检测设备）
- **项目本质**：手机中框的自动上料与视觉检测线，含长输送线、叠盘、顶升移栽、龙门架、取料组件、机架外罩

## 核心机构 / 模块

| 模块 | 说明 |
|------|------|
| 长输送线（下料长皮带线） | 工件主输送 |
| 分盘线 | 料盘分料 |
| 顶升移载输送线 | 工位间移栽 |
| 龙门架 | 跨线搬运，含直线电机、视觉组件、抓手 |
| 上机架总装 / 底部机架总装 | 设备骨架 |
| 产品 | 检测对象 |

## 关键技术点

- 视觉检测（Mark 点对位 / 边缘定位）节拍与精度
- 上料机的多机构协同
- 直线电机应用（龙门架高速搬运）
