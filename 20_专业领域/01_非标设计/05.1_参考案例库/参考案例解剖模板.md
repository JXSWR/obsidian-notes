# 参考案例解剖模板

> **用途**：给新增课程案例搭 4 篇骨架。复制本文四次，按 `参考案例NNN-0X类型` 命名后填内容。
> NNN = 案例编号（必带，防 5 个案例的「01项目简介」互相错链）。
> **铁律**：不设「复盘笔记」章节——课程案例填不出复盘，加了只会制造 TODO 欠债（详见 [[案例索引]]）。

## 拆解产物（每案例 4 篇）

| 文件 | 装什么 | 回答什么 |
| :--- | :--- | :--- |
| `参考案例NNN-01项目简介.md` | 需求 + 方案 + 决策理由 | 客户要什么、怎么实现、为什么这么选 |
| `参考案例NNN-02案例卡片.md` | 目录页：一页看清有什么 | 这台设备有哪些模块、资产、文件 |
| `参考案例NNN-03可复用提取.md` | **可迁移的判断规则** | 下次能抄什么规则 |
| `参考案例NNN-04知识点汇总.md` | **这台设备的具体知识**（机构/要点/参数/BOM） | 这台设备里有什么 |

> 03 与 04 的分工：03 不放案例专属数字（抄参数误导下个项目）；04 放（本来就是本案例的参数）。
> 03 中成型的好规则 → 提炼进 `07_可复用卡/`（产物去向）。

```markdown

【填：客户原始约束，逐条列出】

## 方案概述
- 布局：…/ 关键机构：…/ 关键参数：
【填：最终方案的形态与核心参数】

## 为什么选这个方案？
1. 【填：被否决的方案与理由】
2. 【填：核心决策理由——对比中排除谁、为什么】
【填：3~5 条，这是 03 可复用提取的原料来源】

## 参考机构
- [[TODO:机构名]]、【填：需要沉淀的机构，先占位】

## 参考公式
- 【填：用到的计算，链接公式库/计算列表】

## 模型文件
- 模型说明：`参考案例NNN-04知识点汇总`
- STEP/3D：`./项目3D文档/`（E 盘外置，写绝对路径）
```

## 新增案例流程（速查）

1. 建目录 `00N_项目名/`（E 盘大文件同编号）
2. 复制本文 → 生成 4 篇 → 按 `参考案例NNN-0X类型` 命名
3. 大文件放 E 盘，md 里写绝对路径
4. 回填 [[案例索引]]「四件套一览表」与 [[00_案例总览]]

> 完整定位与规则见 [[案例索引]]。
