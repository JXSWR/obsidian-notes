## 二、案例专属参数

> 只属于这个项目的数字。**不进可复用卡** —— 抄参数会误导下一个项目，抄判断规则不会。

| 项 | 值 |
| :--- | :--- |
| 产品 | 成形玻璃（大片），CNC 加工件 |
| 节拍 | CNC 加工 4 min/片，上下料须 < 4 min |
| 上料精度 | ±5 mm |
| 物料 | Tray 盘 450×300，人工一摞放取 |
| 机器人 | 6 轴 RS007L，臂展 930mm，负载 7kg，自重 36kg |
| 导轨 | HGH15CA，动载荷约 1 吨 |
| CNC 间距 | 1.6 m |
| 环境 | 水雾大、地面湿 → 整机防锈防水，加工后玻璃需尽量干燥 |

## 三、机构清单

| 机构 | 说明 | 可复用性 |
| :--- | :--- | :--- |
| 地轨 + 机器人小车 | H 型钢 + 齿轮齿条 + 磁栅尺闭环，长行程往返 | 高 —— 长行程搬运通用范式 |
| 六轴机器人 + 双面吸盘抓手 | RS007L，取放合一 | 高 —— 见 真空吸附搬运 |
| Tray 盘缓存上下料 | 450×300 盘，人工一摞放取 | 高 —— 跨 001/003/004/005 |
| 中心定位机构 | 保证上料精度 ±5mm | 中 —— 精度要求随产品变 |
| 研发设计库（标准件 3D 库） | 丝杆/气动接头/电机/传感器等现成模型 | 中 —— 是资源不是知识 |
