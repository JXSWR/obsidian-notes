## 二、机构清单

| # | 机构 | 说明 |
| :--- | :--- | :--- |
| 1 | 地轨机构 | H 型钢 + 齿轮齿条 + 磁栅尺，机器人小车长行程往返 |
| 2 | 六轴机器人上下料 | RS007L，双面吸盘抓手（取未加工 / 放已加工） |
| 3 | Tray 盘缓存上下料 | 450×300 Tray 盘，人工放/取一摞 |
| 4 | 中心定位机构 | 保证上料精度 ±5mm |

## 三、设计要点

- **选磁栅尺不选光栅尺** —— 现场水雾大，光栅尺积水影响透光性；磁栅尺不受水雾影响
- **地轨用矮宽 H 型钢** —— 重心低，稳定性好
- **安装条间会积水淤积** → 必须加整体安装大板
- **CNC 不能有等待时间** —— 上下料节拍必须 < 4 min

## 四、关键选型与实测参数

### 机器人

| 项 | 值 |
| :--- | :--- |
| 类型 / 型号 | 6 轴 / **RS007L** |
| 臂展 | 930 mm |
| 负载 | 7 kg |

| 选型理由 | 双面吸盘抓手需 6 轴灵活度；负载轻（玻璃 + 吸盘） |

### 传动方案对比 ⭐

| 方案 | 结论 | 理由 |
| :--- | :---: | :--- |
| 丝杆 | ❌ 排除 | 行程太长 |
| 同步带 | ❌ 排除 | 负载大、启停频繁，易断 |
| **齿轮齿条** | ✅ **选用** | 适合长行程大负载 |
| 直线电机 | ❌ 排除 | 成本太贵 |

### 其他关键件

| 名称 | 型号 / 规格 | 说明 |
| :--- | :--- | :--- |
| 位置反馈 | **磁栅尺闭环** | 非光栅尺，理由见设计要点 |
| 直线导轨 | **HGH15CA** | 动载荷约 1 吨（查样册） |
| H 型钢 | 矮宽型 | 地轨结构焊件 |
| 吸盘抓手 | 双面（定制） | 一面取料一面放料 |

## 五、地轨结构细节 ⭐

- **材料**：H 型钢（矮宽型，重心低）
- **安装面**：H 型钢表面焊接安装条，安装条表面需精加工
- **坑点**：安装条之间会积水淤积 → 必须加整体安装大板
