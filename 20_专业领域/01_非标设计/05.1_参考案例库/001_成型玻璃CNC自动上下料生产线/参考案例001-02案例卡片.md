# 案例卡片 · 11期 成形玻璃CNC自动上下料生产线

- **期数**：第 11 期
- **行业**：玻璃深加工 / CNC 加工
- **产品对象**：成形玻璃（大片）CNC 加工件的自动上下料
- **项目本质**：在 CNC 加工中心前后布置自动上下料线，实现工件「上料缓存 → 加工 → 下料 → 分拣」全自动，减少人工干预

## 核心机构 / 模块

| 模块 | 说明 |
|------|------|
| 自动上下料线 | 上料缓存 + 下料缓存，对接 CNC |
| 中心定位机构 | 保证工件上料定位精度 |
| 移栽 / 搬运 | 工件在缓存区与 CNC 间的搬运 |
| 研发设计库（标准件 3D 库） | 含丝杆、气动接头、电机、传感器、开关等标准件模型 |

## 关键技术点

- 大片玻璃的真空吸附与防碎设计
- 上下料节拍与 CNC 加工节拍匹配
- 中心定位精度保证

## 可复用资产

- 研发设计库：一套现成的标准件 3D 模型库，可直接借用到其他项目
- 上下料线 + 定位 + 移栽的布局范式
- 完整项目输出文件：规格书、作业指导书、评审报告、项目进度表、物料清单
