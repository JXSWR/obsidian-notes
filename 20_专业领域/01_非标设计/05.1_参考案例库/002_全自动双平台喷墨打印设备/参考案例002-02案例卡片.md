# 案例卡片 · 12期 全自动双平台喷墨打印设备

- **期数**：第 12 期
- **行业**：喷墨 / 字符打印（非标自动化）
- **产品对象**：工件表面字符 / 图案的双平台喷墨打印
- **项目本质**：双平台交替工作，一侧打印时另一侧上下料，提升设备综合效率（OEE）

## 核心机构 / 模块

| 模块 | 说明 |
|------|------|
| 双打印平台 | 交替作业，节拍优化核心 |
| 喷墨打印头组件 | 字符 / 图案喷印 |
| 输送与定位 | 工件进给与打印位定位 |
| XWZ01-A0 喷墨打印设备 | 完整 3D 方案，含7个子单元 |

## 关键技术点

- 双平台节拍分配与防干涉
- 喷墨定位精度
- 平台切换的同步控制逻辑
