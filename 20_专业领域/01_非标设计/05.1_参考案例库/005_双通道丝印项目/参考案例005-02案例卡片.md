# 案例卡片 · 15期 双通道丝印项目

- **期数**：第 15 期
- **行业**：丝印 / 印刷（非标自动化）
- **产品对象**：双通道高精度转盘式丝印机
- **项目本质**：转盘式双通道丝印，配 tray 盘缓存机与叠盘机构，含完整的项目管理实战（需求解析→布局→2D/3D→规格书→报价→出图→BOM→发包）

## 核心机构 / 模块

| 模块 | 说明 |
|------|------|
| 吸式丝印机 | 吸附式丝印核心 |
| 圆盘丝印机 | 转盘式多工位丝印 |
| Z轴主传动 | 丝印刮板升降 |
| X轴主传动 | 刮板水平运动 |
| 刷板传动（D模块） | 刮墨/回墨，含THK交叉导轨、汽缸 |
| 网架安全护栏 | 丝网夹持与安全防护 |
| F1圆盘 / F2平台 | 转盘与吸附平台 |
| tray 盘缓存 / 叠盘 | 料盘缓存与堆叠 |
| 视觉对位 | Mark 点对位 / 边缘定位（见原理图 png） |

## 关键技术点

- 转盘双通道节拍分析与平衡（`双通道高精度丝印机节拍分析.xlsx`）
- 丝印对位精度（视觉）
- 完整项目管理流程（含报价、BOM、发包）
- 吸式 vs 圆盘两种丝印方案对比
