# 参考案例005 · 双通道丝印项目 — 可复用提取

> [!warning] 本案例是**课程案例**（小丸子 VIP 第 15 期，嘉文老师），非本人亲历。
> 所以这里**不做个人复盘**。本页只回答：**这台设备里，有什么是下次能抄的？**

> 格式样板见 [[参考案例001-03可复用提取]]。

---

## 一、可迁移的判断规则

| # | 规则 | 出处 | 提炼状态 |
| :--- | :--- | :--- | :--- |
| 1 | **同一设备上做两套方案做对照** —— F1 圆盘（分割器驱动）vs F2 吸附平台，是难得的同条件对照样本 | [[参考案例005-04知识点汇总]] 模块清单 | ⬜ 待提炼（**方法论价值高**） |
| 2 | **双通道提效** —— 并行通道提升产能，与 002 双平台是同一思路的不同实现 | 同上 设计要点 | ⬜ 待提炼（与 002 合并成一张「并行化提效」卡） |
| 3 | **Z 轴用丝杆、X 轴用时规皮带** —— 按轴的功能选传动：升降要精度与自锁，平移要行程与速度 | 同上 模块清单 | ⬜ 待提炼 |
| 4 | **视觉对位（Mark 点 / 边缘）保证丝印精度** | 同上 设计要点 | ⬜ 待提炼（与 004 合并研究） |
| 5 | **Tray 盘叠料缓存** —— 人工一摞放取，覆盖人工间隔 | 模型文件 `TRAY盘叠料缓存机构.rar` | ⬜ 待提炼（**跨 001/003/004/005，通用性最强之一**） |

> **第 1 条最值钱**：同一台设备上并列两种方案，这种设计在日常项目里几乎不可能出现
> （成本不允许）。课程案例的稀缺价值就在这里——**能看到被现实成本过滤掉的对照**。

## 二、案例专属参数

| 项 | 值 |
| :--- | :--- |
| 零件数 | 约 232 文件（五案例中最少） |
| Z 轴 | 丝杆驱动刮板升降 |
| X 轴 | 时规皮带驱动刮板水平 |
| 刷板传动 | THK 交叉导轨 + 气缸 |
| 分割器 | CRB1BW100-180S-XF（F1 圆盘） |
| 滑轨 | HSR-20R 滑块 |
| 轴承 | 30205 / 6002ZZ / 6003ZZ |

## 三、机构清单

| 机构 | 说明 | 可复用性 |
| :--- | :--- | :--- |
| F1 圆盘（分割器） | 转盘式丝印工位 | 高 —— 见 转盘与分割器 |
| F2 吸附平台 | 吸附式丝印工位 | 高 —— 见 真空吸附搬运 |
| B/C 轴传动 | 丝杆 + 时规皮带 | 中 |
| D 刷板传动 | 刮墨/回墨 | 中 —— 丝印专用 |
| Tray 盘叠料缓存 | 人工一摞放取 | 高 —— 跨 4 个案例 |
