## 一、设备概况

| 项 | 值 |
| :--- | :--- |
| 功能 | 双通道高精度转盘式丝印机，含**吸式丝印 + 圆盘丝印两种方案** |
| 零件数 | 约 232 文件（五个案例中零件最少） |
| 原始软件 | SolidWorks，导出 STEP |

## 二、模块清单（A–F）

| 代号 | 模块 | 说明 |
| :--- | :--- | :--- |
| A | 机架 | 吸式 / 圆转盘 / 通用，含装配图和电箱 |
| B | Z 轴主传动 | **丝杆**驱动刮板升降 |
| C | X 轴主传动 | **时规皮带**驱动刮板水平运动 |
| D | 刷板传动 | 刮墨 / 回墨，**THK 交叉导轨 + 气缸** |
| E | 网架安全护栏 | 丝网夹持与安全防护 |
| F1 | 圆盘 | 转盘式丝印工位，**分割器驱动** |
| F2 | 平台 | 吸附式丝印工位 |

## 四、设计要点

- **双通道转盘设计提升产能**
- **吸式 vs 圆盘两种丝印方案可对比** —— 同一台设备上做了两套工位，是难得的对照样本
- **视觉对位（Mark 点 / 边缘定位）保证丝印精度**
- 节拍分析见独立 xlsx：`双通道高精度丝印机节拍分析.xlsx`
