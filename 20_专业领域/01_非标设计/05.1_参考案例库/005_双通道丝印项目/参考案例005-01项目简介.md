# 案例005：双通道丝印项目 — 需求与方案

## 客户需求
- 产品：双通道高精度转盘式丝印机
- 工艺：丝印（吸式丝印 + 圆盘丝印两种方案）
- 核心诉求：转盘双通道、高精度、含完整项目管理流程

## 方案概述
- 布局：**双通道转盘式**，含吸式丝印机 + 圆盘丝印机两种丝印方案
- 核心模块：A-机架 / B-Z轴主传动 / C-X轴主传动 / D-刷板传动 / E-网架安全护栏 / F1圆盘 / F2平台
- 辅助机构：Tray盘缓存 / 叠盘 / 视觉对位
- 管理：需求解析→布局→2D/3D→规格书→报价→出图→BOM→发包 完整流程

## 为什么选这个方案？
1. 双通道转盘提升产能
2. 吸式+圆盘两种丝印方案可对比选型
3. 视觉对位保证丝印精度（Mark点对位 / 边缘定位）
