## 四、翻转方案对比 ⭐

| 方案 | 评价 |
| :--- | :--- |
| 旋转气缸 | 竖直→水平速度慢；水平→竖直快，**易回弹** |
| 电机 | 运动平稳，但不好看、不对中 |
| 气缸 + 齿轮齿条 | 可选 |
| 侧姿气缸 | 可选 |
| 连杆机构 | 可选 |

## 五、设计要点

- **5 分钟人工间隔 + 不停机** → 缓存机构需 ≥ 3 篮子
- **一次吸附 3 片玻璃** —— 提效但需保证真空可靠性
- **±0.1mm 精度易达** —— 同步带 ±0.04mm / 丝杆 ±0.02mm 远超要求（**精度不是本设备的选型瓶颈**）
- **玻璃翻转方案需慎重** —— 旋转气缸水平→竖直速度快易回弹
