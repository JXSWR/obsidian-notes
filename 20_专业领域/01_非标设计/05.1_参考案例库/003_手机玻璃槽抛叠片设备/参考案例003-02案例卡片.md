# 案例卡片 · 13期 手机玻璃槽抛叠片设备

- **期数**：第 13 期
- **行业**：玻璃 / 抛光（3C 手机玻璃）
- **产品对象**：手机玻璃的槽式抛光与叠片
- **项目本质**：对手机玻璃进行槽式抛光处理，并用叠片机构将成品规整堆叠

## 核心机构 / 模块

| 模块 | 说明 |
|------|------|
| 槽抛机构 | 玻璃槽式抛光核心工位 |
| 叠片机构 | 成品自动堆叠 |
| 交替升降单元 | 工件在抛光与叠片间的流转 |
| 龙门机械手 | 跨工位搬运 |
| 等距移栽机构 | 多工位等距输送 |
| 转盘上料 / 旋转下料 / 圆带下料 | 上料与下料多种方式 |

## 关键技术点

- 玻璃抛光工艺参数与防划伤
- 叠片定位与整齐度
- 多单元协同节拍

## 可复用资产

- 7 讲课程讲义（PDF + XMIND），流程示范完整
- 槽抛 + 叠片组合工艺的设备范式
- 多种上料/下料机构方案（转盘/旋转/圆带）可横向对比
