# 案例003：手机玻璃槽抛叠片设备 — 需求与方案

## 客户需求
- 产品：手机玻璃
- 工艺：槽式抛光 + 叠片
- 节拍：2340 pcs/h
- 精度：定位 ±0.1mm（同步带模组±0.04mm，丝杆模组±0.02mm）
- 设备尺寸：最大 5m×5m
- 人工间隔：5分钟上下料一次，上下料阶段不能停机
- 缓存要求：每次最少缓存3个篮子的物料
- 安全防护：安全光栅、门禁开关
- 特殊要求：玻璃表面不能有污染

## 方案概述
- 布局：多单元组合（8个子单元）
- 玻璃搬运：真空吸附，一次吸附3片
- 核心机构：槽抛 / 叠片 / 交替升降 / 龙门机械手 / 等距移栽 / 转盘上料 / 旋转下料 / 圆带下料
- 玻璃翻转：从竖直到水平（旋转气缸/电机/气缸+齿轮齿条/侧姿气缸/连杆机构可选）

## 为什么选这个方案？
1. 5分钟人工间隔+不停机 → 必须有缓存机构（3篮子）
2. 一次吸附3片 → 提效，但需保证吸附可靠性
3. ±0.1mm精度不难达到（同步带/丝杆模组精度远超要求）
4. 多种上料/下料方式（转盘/旋转/圆带）适配不同工况
