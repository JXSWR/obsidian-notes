## 一、需求背景

做一款**柔性滑柱仿形夹具**，把滑柱做成真空吸附组件，实现鞋底的定位与固定。

| 需求项 | 内容 |
| :--- | :--- |
| 覆盖范围 | 一个夹具适用 **200–360mm** 全鞋码 |
| 固定方式 | 真空吸附 |
| 定位方式 | 工装仿形限制运动方向 |
| 应用场景 | 鞋底**上表面**与工装贴合，抛光机对**底面与四周**抛光 |
| 名称澄清 | 叫「夹具」，实则是参考市面柔性滑柱仿形夹具的**原理**，并不需要其夹紧功能——称作「工装」更准确 |

> 💡 名称上的这个澄清很重要：市面上买的是**夹持**方案，你要的只是**仿形贴合 + 吸附**。
> 需求定义时先想清楚「到底要不要夹紧」，能砍掉一整个功能分支。

---

## 二、机构原理

**针床式仿形（Pin-Array Conforming）**：用一片可独立升降的密集滑柱阵列去逼近鞋底曲面，锁死后柔性阵列变为**刚性型腔**，实现一套硬件适配全鞋码。

> **支撑柱排列**：奇偶行交错密排（相邻行错位半个节距）——
> 比整齐方阵的等效间隙更小，对鞋底这类曲率变化大的软质工件尤为重要。

### 三层功能架构

| 层级 | 功能 | 内容 |
| :--- | :--- | :--- |
| **① 仿形层** | 贴合轮廓 | 支撑柱（多数）被动浮动提供刚性面；吸附柱（少数）密封吸嘴建立真空 |
| **② 锁定层** | 柔性→刚性切换 | 螺栓 + 铁压块机械锁死单排滑柱 |
| **③ 基座层** | 承托 + 气路 | 导向板（定节距）、真空腔、气路分配、传感器 |

## 三、技术决策（已定）

| 决策项 | 方案 | 理由 |
| :--- | :--- | :--- |
| **滑柱驱动** | 弹簧复位 | 仅将滑柱推回初始高度；贴合靠压紧机构压到位。结构最简单，无额外气源 |
| **柱阵分工** | 支撑柱（多数）+ 吸附柱（少数） | 支撑柱纯机械仿形承重（便宜、密排）；吸附柱只布在关键锚点防翘（气路简单） |
| **吸附分区** | 按鞋码分 2–3 组，每组独立气阀 | 远鞋码不盖到的组关阀防漏气；分区少，调试量可控 |
| **锁定方式** | 机械手柄 + 螺栓 + 铁压块（按排锁紧） | 手柄拧紧→螺栓下压→铁块横向挤压→整排锁死。仅需人力，**无需锁紧气源** |
| **模块化策略** | 路线 B：增减行模块适配鞋码 | 每排 = 独立模组，基座预留安装孔阵列。详见第五节 |

### 吸附柱规格（2026-07-19 确定）

| 参数 | 值 |
| :--- | :--- |
| 吸附柱外径 | **Φ12mm** |
| 中心气孔 | Φ4.2mm → 攻 **M5×0.8** 螺纹 |
| 吸盘型号 | **SMC ZP2-TS10-GE-A5** |
| 吸盘直径 | Φ10mm（< 柱头 Φ12，不干涉相邻柱） |
| 吸盘材质 | 导电性 EPDM 海绵（适配鞋底曲面） |
| 连接方式 | M5×0.8 外螺纹，直接拧入滑柱顶端 |
| 真空路径 | 纵向抽气，螺纹中心通孔与滑柱 Φ4.2 气孔直通 |

**锚点布置**：前掌 1–2 个（防翘）、中段足弓 2–4 个（主吸附区，最平坦）、后跟 1 个（重心区）。起步 5–8 个。

## 四、动作时序

```
放料 → 柱阵浮起轻触鞋底 → 压紧到位 → 手柄锁死全部柱（定形）
     → 吸附柱抽真空（拉紧）→ [加工] → 破真空 → 解锁 → 取料
```

> ⚠️ **时序铁律：先锁死，再抽真空。**
> 若先抽真空，鞋底会被局部吸陷，破坏仿形面。
> 这是本项目最容易被忽略、代价又最高的一条——装调时顺序错了，工件直接报废。

---

## 五、模块化策略（路线 B）

每排 = 一个独立模组，基座预留等间距安装孔阵列。换鞋码时前后端增/减行模块，**足弓区行数不变**。

| 鞋码 | 前掌区 | 足弓区 | 后跟区 | 总排数 |
| :--- | :--- | :--- | :--- | :--- |
| 200mm（最小） | N 排 | M 排（固定） | N 排 | M + 2N |
| 360mm（最大） | N+Δ 排 | M 排（固定） | N+Δ 排 | M + 2(N+Δ) |

**三条关键决策**：
- 吸附柱跟模块走 —— 每排固定 1–2 个吸附柱位，换型时天然跟随，无需单独调气路
- 安装接口 —— 基座全长等间距孔，行模块快拆（螺栓/销钉）
- 换型操作 —— 增减前后端行模块 + 调节吸附分区气阀开闭

### 路线对比（为什么选 B）

| | 路线 A（可调排间距） | 路线 B（增减行模块）✅ | 路线 C（三区+过渡区） |
| :--- | :--- | :--- | :--- |
| 柱密度 | 间距拉开后变稀 ❌ | 始终均匀 | 基本均匀 |
| 换型操作 | 松螺丝→滑动→锁死 | 拆装行模块 | 调中间几排 |
| 适用性 | 柱密度下降影响定型 | 模块化程度高 | 前后端在鞋码变化中并非稳定区 ❌ |

## 六、待计算项

- ⬜ 节距确认：鞋底轮廓 → 支撑柱数量（**8–10mm 起步校核**）
- ⬜ 吸附柱定数：极端鞋码（200 / 360mm）各覆盖几个
- ⬜ 弹簧选型：复位力校核（F ≥ 滑柱自重 + 复位裕量）
- ⬜ 真空吸附力校核：单吸嘴吸力 × 有效吸嘴数 vs 所需夹持力
- ⬜ 手柄锁紧力校核（扭矩 → 推力 → 铁压块抱紧力）
