## 一句话概括

用一片可独立升降的滑柱阵列逼近鞋底曲面、锁死后变成刚性型腔的仿形工装——一套硬件适配 200–360mm 全鞋码，滑柱本身兼作真空吸嘴。

## 项目本质

解决「**柔性工件 + 多规格**」的定位固定矛盾：
仿形层贴合曲面 → 锁定层把柔性变刚性 → 吸附柱在关键锚点拉紧。

> 关键洞察：这不是夹具，是**工装**。市面产品卖的是「夹持」，你要的只是「仿形贴合 + 吸附」——
> 想清楚这一点，直接砍掉了整个夹紧功能分支。

---

## 核心模块

| 模块 | 说明 |
| :--- | :--- |
| 仿形层 | 支撑柱（多数，球头）+ 吸附柱（少数，海绵吸盘头） |
| 锁定层 | 手柄 + 螺栓 + 铁压块，按排机械锁死 |
| 基座层 | 导向板（定节距）、真空腔、气路分配、传感器 |
| 行模块 | 每排 = 独立模组，快拆，换鞋码时增减 |
| 气路 | 仅真空（**无锁紧气源**），2–3 组分区独立气阀 |

## 关键技术点

- **针床式仿形原理**：柔性阵列 → 刚性型腔的状态切换
- **奇偶行交错密排**：等效间隙比方阵小，适配曲率变化大的软质件
- **先锁死、再抽真空**：顺序反了工件会被局部吸陷
- **支撑柱与吸附柱分工**：便宜的做承重，贵的只布在关键锚点
- **模块化行单元**：换型靠增减行模块，不靠调间距

## 可复用资产

- **针床式仿形**这套原理本身（通用性极高，不限于鞋底）
- 拆机得到的**锁定层方案**（手柄+压块 vs 气囊的对比结论）
- 「柔性→刚性切换」的结构范式
- 23 张市面产品拆机照片（在过程笔记）
