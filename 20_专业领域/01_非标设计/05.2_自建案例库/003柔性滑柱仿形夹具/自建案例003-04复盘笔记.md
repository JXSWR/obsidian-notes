## 一、方案推翻记录 ⭐ 本项目最有价值的一段

> 2026-07-14，拆解市面产品后，锁定层方案**推倒重来**。

**原方案**：气囊侧抱锁紧（气源驱动）
**实物方案**：机械手柄 + 螺栓 + 铁压块（手动）

| 对比项 | 原方案（气囊锁紧） | 实物方案（手柄+压块） |
| :--- | :--- | :--- |
| 锁紧原理 | 气囊侧抱，气源驱动 | 螺栓 + 铁压块，手动 |
| 气源需求 | 锁紧气源 **+** 真空气源 | **只需真空** |
| 结构复杂度 | 气囊、密封、管路 | 一个手柄 + 螺栓 + 压块 |
| 换型操作 | 自动（但**过度设计**） | 手动（量大几乎不换，完全够用） |
| 🔴 吸附柱兼容冲突 | 存在 | **不存在** |

### 派生决策（连锁反应）

- **砍掉锁紧气源** —— 整机气路只剩真空，大幅简化
- **弹簧仅做复位** —— 从「浮动窗口」简化为一侧约束（F ≥ 自重 + 复位力），选型难度骤降
- **模块化行单元** —— 每排 = 独立模组（滑柱阵列 + 锁紧手柄 + 快插气接头）
- **锁紧力校核重算** —— 从「气囊摩擦力」改为「手柄扭矩 → 螺栓推力 → 铁压块抱紧力」

### 这段记录为什么值钱

1. **它证明了「先拆再设计」的回报** —— 23 张照片换来一条气路的取消和一个结构冲突的根除
2. **它暴露了一个思维习惯** —— 原方案选气囊是为了「自动换型」，但**量大时几乎不换型**，
   为一个不存在的场景付了复杂度税。这类过度设计，自己设计时很难察觉
3. **它是 A 级素材** —— 这是你的决策，不是课程的

## 二、已识别风险与对策

| 风险 | 对策 | 状态 |
| :--- | :--- | :--- |
| 吸附柱在浮动面上漏气 | 吸嘴用波纹/海绵密封结构，**不可用硬吸嘴** | ✅ 已定（EPDM 海绵吸盘） |
| 支撑柱节距过大 → 软鞋底柱间下凹 | 节距取 8–10mm 起步校核 | ⬜ 待计算 |
| 手柄锁紧力不足 → 加工时柱缩回 | 需校核（扭矩 → 推力 → 抱紧力 vs 加工反力） | ⬜ 待计算 |
| 弹簧力不足无法复位 | F ≥ 滑柱自重 + 复位裕量（上限不严苛） | ⬜ 待选型 |
| ~~吸附柱锁紧与真空结构冲突~~ | 手柄外部锁紧天然规避 | ✅ 已解决（2026-07-14） |

## 三、待办计算（项目推进前必须闭环）

- ⬜ 节距确认：鞋底轮廓 → 支撑柱数量
- ⬜ 吸附柱定数：极端鞋码（200 / 360mm）各覆盖几个
- ⬜ 弹簧选型：复位力校核
- ⬜ 真空吸附力校核：单吸嘴吸力 × 有效数 vs 所需夹持力
- ⬜ 手柄锁紧力校核

> 这 5 项任一项跳过，都可能在加工阶段变成返工。
> 尤其是**手柄锁紧力**——它是本项目唯一靠人力保证的关键力，没有传感器兜底。
