## 一、项目目标

自动化鞋底抛光机：**双工位二维轨迹 + 对位仪 + 真空吸附**。

核心思路是**集成三台参考设备各自的长处**，而非从零设计：

| 参考设备 | 取用的部分 |
| :--- | :--- |
| 设备一 | 气缸底抛结构布局 |
| 设备二 | 长度计算与居中功能 |
| 设备三 | 真空吸夹具 |

> 💡 这个做法本身就是一条可迁移的方法——**非标设计很少从零开始，多数是拼装已知方案并解决拼装产生的新矛盾**。
> 真正的设计量集中在「三家的东西怎么长到一起」。

---

## 二、核心参数

| 项 | 值 |
| :--- | :--- |
| 加工产品 | 鞋底，**200–360mm 多种款式** |
| 设备外形 | ≤ 2000 × 1800 × 2000 mm |
| 底部抛光 | 气缸底抛（来自设备一） |
| 侧面抛光 | **3HP 卧式伺服电机** + 布轮（8 英寸 / 内孔 25.4mm） |
| 上料方式 | **人工上料** |
| 夹具方式 | **真空吸**（来自设备三） |
| 运动控制 | **EtherCAT 总线**，支持多轴同步与轨迹插补 |
| 控制器候选 | 汇川 AC800 系列 / 台达 AX 系列 |

---

## 三、系统组成

### 运动系统
- **气缸底抛** —— 底部抛光
- **伺服侧面抛光** —— 3HP 卧式伺服 + 布轮
- **二维轨迹平台** —— XY 方向运动控制

### 定位系统
- **对位仪** —— 检测鞋底位置偏移，补偿到 XY 运动轨迹
- **长度计算与居中** —— 来自设备二

### 夹具系统
- **真空吸夹具** —— 来自设备三
- 吸附组件材质、密封条槽宽槽深 —— **待定**（见 [[自动化鞋底抛光机]]）

## 四、关键决策记录

> 决策卡格式：**场景 → 候选 → 选择+理由 → 边界**。
> 「理由」空白的，说明当时是直觉选择——这类决策最值得事后补记，因为直觉里往往藏着没说出来的经验。

| 决策点 | 选择 | 理由 | 边界 / 待验证 |
| :--- | :--- | :--- | :--- |
| 底部 vs 侧面抛光驱动 | 底部**气缸** + 侧面**伺服** | ❓ 待补 | 为何不统一？成本 / 压力控制 / 精度要求差异 |
| 传动方式 | 梯形丝杆 | ❓ 待补 | 为何不用滚珠丝杆（成本 / 自锁 / 速度） |
| 总线 vs 脉冲 | EtherCAT 总线 | 多轴轨迹插补 | 轴数临界点在哪 |
| 工位数 | 双工位 | ❓ 待补 | 节拍算过吗？瓶颈在抛光还是上下料 |
| 上料方式 | 人工 | ❓ 待补 | 是成本妥协，还是节拍本就够用 |
