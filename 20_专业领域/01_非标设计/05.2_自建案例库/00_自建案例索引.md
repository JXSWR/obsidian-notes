1. **内容只存一处** —— 两边**链接互指，不复制内容**（复制必漂移，同一件事会写成两个版本）
2. **过程笔记永久保留** —— 决策依据、疑点、踩坑记录是全库最值钱的资产，绝不删除
3. **进行中也可以建案例** —— 但复盘章节等完工再填；趁记忆还热，先把卡点和决策理由记下来

## 案例标准结构（四件套）

```
00N项目名/
├── 自建案例NNN-01项目简介.md     ← 需求 + 方案 + 决策理由
├── 自建案例NNN-02案例卡片.md     ← 目录页：一页看清有什么、能抄什么
├── 自建案例NNN-03可复用提取.md   ← 什么值得抄 → 链接到 07_可复用卡/
└── 自建案例NNN-04复盘笔记.md     ← 做对了 / 踩坑 / 如果再来一次
```

> ⚠️ **文件名 `自建案例NNN-0X类型`：案例编号必带。**
> 3 个案例若都叫「01项目简介」，该链接 会**静默指向错的那一篇**——
> 不断链、不报错，但点进去是别的项目。参考案例侧对称使用 `参考案例NNN-0X类型`，
> 两类前缀不同，一眼可分本人项目与课程案例。

**与参考案例的关键差异**：这里**有复盘章节，且必须填**。
参考案例不设复盘（没做过的项目写不出踩坑），本人项目的复盘填得出来，它是全库可信度最高的内容。

## 素材等级

| 等级 | 含义 | 升级路径 |
| :---: | :--- | :--- |
| **A** | 亲历验证 —— 本项目实战跑过 | 实战跑通后标记 |
| **B** | 课程提炼 —— 理论成立但本人没做过 | 经本项目验证后升 A |
| **B+** | 本人设计 —— 结构成立，待实物验证 | 加工装配验证后升 A |
| **C** | 推算 —— 公式或 AI 推导，未实测 | 实测后升 B |

> **当前 A 级卡 = 0 张。** 001 是最快能产出 A 级卡的项目——它已完成，只差你说出来。
