# 薄壁件加工

## 加工难点
- 刚性差，受切削力易变形
- 壁厚 < 2mm 时振动敏感
- 容易因残余应力导致尺寸超差

## 应对策略
| 问题 | 对策 |
| :--- | :--- |
| 振刀 | 减小径向切宽 ae，增加轴向切深 ap（反之亦然） |
| 变形 | 对称加工、分多次走刀、释放应力 |
| 装夹 | 增加辅助支撑、使用真空吸盘 |

## 参数调整
- 线速度：提高 20%（减少切削力）
- 每齿进给：减小 30%
- 切深：浅吃快跑（ap 小、速度快）

## 推荐策略
- 动态铣优先（切削力稳定）
- 全精加工分 2~3 刀完成
- 最后 0.1~0.2mm 余量做光刀
