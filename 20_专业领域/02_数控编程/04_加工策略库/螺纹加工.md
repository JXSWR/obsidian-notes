# 螺纹加工

## 方法对比
| 方法 | 适用 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| 丝锥攻丝 | M1~M20 | 效率高 | 断刀风险 |
| 螺纹铣削 | M6以上 | 通用、精度高 | 程序复杂 |
| 车螺纹 | 轴类外螺纹 | 精度高 | 需专用刀 |

## 螺纹铣削参数
| 螺纹规格 | 刀片类型 | 转速 (rpm) | 进给 (mm/min) |
| :--- | :--- | :---: | :---: |
| M6 | 螺纹铣刀 φ6 | 3000~5000 | 200~300 |
| M10 | 螺纹铣刀 φ10 | 2000~4000 | 250~400 |
| M16 | 螺纹铣刀 φ12 | 1500~2500 | 300~500 |

## 底孔直径
- 切削攻丝底孔 ≈ 螺纹大径 - 螺距
- 挤压攻丝底孔 ≈ 螺纹大径 - 0.5×螺距
