# 钻孔与镗孔

## 钻孔循环
| G代码 | 动作 | 适用 |
| :--- | :--- | :--- |
| G81 | 钻孔+快速退刀 | 浅孔、通孔 |
| G82 | 钻孔+暂停+退刀 | 沉孔 |
| G83 | 啄钻+完全退刀 | 深孔 (L>3D) |
| G73 | 啄钻+断屑退刀 | 深孔排屑好 |

## 镗孔循环
| G代码 | 动作 | 适用 |
| :--- | :--- | :--- |
| G85 | 镗孔+快速退刀 | 粗镗 |
| G86 | 镗孔+主轴停+退刀 | 精镗 |
| G76 | 镗孔+主轴定向+偏置退刀 | 高精度镗孔 |

## 注意事项
- 钻头直径 < 3mm 时转速 ≥ 8000rpm
- 镗孔后退刀前确认主轴已停
- 交叉孔加工时减小进给
