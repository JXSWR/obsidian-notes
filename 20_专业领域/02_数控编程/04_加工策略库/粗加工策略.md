# 粗加工策略

## 动态铣削（摆线）
- **特点**：刀具全刃切削，径向切宽小（ae ≤ 0.3D）
- **优势**：切削力稳定，刀具寿命长
- **适用**：深腔、硬材料、大切深
- **参数**：ae = 0.1~0.3×D, ap = 1~2×D

## 层切
- **特点**：每层固定深度，径向大切宽
- **优势**：效率高，适合大平面
- **适用**：平面开粗、软材料
- **参数**：ae = 0.5~0.8×D, ap = 0.3~0.5×D

## 插铣
- **特点**：轴向进刀，类似钻孔
- **优势**：径向力小，适合深腔
- **适用**：深腔、硬材料开粗
- **参数**：ap = 0.5~1×D, 步距 = 0.5~0.8×D

## 核心原则
- 动态铣优先（刀具寿命长）
- 大切深小切宽 vs 小切深大切宽 → 前者更优
