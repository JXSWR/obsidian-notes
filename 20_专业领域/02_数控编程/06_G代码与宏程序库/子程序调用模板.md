# 子程序调用模板

## 子程序结构（FANUC）
```cnc
O1000                    （子程序号）
G91 G01 Z-5 F100
G04 X1                   （暂停1秒）
G91 G00 Z5
M99                      （返回主程序）
```

## 主程序调用
```cnc
O0001
M98 P1000                （调用子程序 O1000）
M98 P2000 L5             （调用 O2000 重复 5 次）
M30
%
```

## 嵌套调用
主程序 → 子程序A → 子程序B（最多 4 层嵌套）
```cnc
O0001                    （主程序）
M98 P1000
M30

O1000                    （子程序1）
M98 P2000
M99

O2000                    （子程序2）
G91 G01 Z-10 F200
G91 G00 Z10
M99
```

## 注意事项
- 子程序和主程序必须在同一目录
- 嵌套不超过 4 层
- 子程序中使用 G91 相对坐标更安全
