# 常用 M 代码速查

## 主轴与冷却
| M代码 | 功能 |
| :--- | :--- |
| M03 | 主轴正转 |
| M04 | 主轴反转 |
| M05 | 主轴停止 |
| M08 | 冷却开 |
| M09 | 冷却关 |

## 程序控制
| M代码 | 功能 |
| :--- | :--- |
| M00 | 程序暂停 |
| M01 | 选择性暂停 |
| M02 | 程序结束 |
| M30 | 程序结束并返回开头 |
| M98 | 子程序调用 |
| M99 | 子程序返回 |

## 换刀
| M代码 | 功能 |
| :--- | :--- |
| M06 | 自动换刀 |

## 注意事项
- M00 和 M01 常用于首件调试
- M30 前必须抬刀至安全高度
- 使用 M98 调用子程序时确认路径正确
