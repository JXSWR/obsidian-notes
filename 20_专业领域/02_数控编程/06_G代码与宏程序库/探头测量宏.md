# 探头测量宏

> 在线测量常用宏程序模板。

## 单点测量
```cnc
（测X方向单点）
G31 G91 X-20 F100          （触碰）
#100 = #5021               （记录机床坐标X）
G91 X5                     （退回）
```

## 孔心测量
```cnc
（四点测孔心）
G31 G91 X-20 F100
#101 = #5021               （X负方向坐标）
G91 X5
G31 G91 X20 F100
#102 = #5021               （X正方向坐标）
G91 X-5
G31 G91 Y-20 F100
#103 = #5021               （Y负方向坐标）
G91 Y5
G31 G91 Y20 F100
#104 = #5021               （Y正方向坐标）
G91 Y-5
#105 = [#101 + #102] / 2   （孔心X）
#106 = [#103 + #104] / 2   （孔心Y）
G00 X#105 Y#106            （移动到孔心）
```

## 注意事项
- 探头使用前必须校准
- 测量速度 ≤ 100mm/min（避免碰撞损坏探头）
