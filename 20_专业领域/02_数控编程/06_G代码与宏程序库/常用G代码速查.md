# 常用 G 代码速查

## 运动指令
| G代码 | 功能 |
| :--- | :--- |
| G00 | 快速定位 |
| G01 | 直线插补 |
| G02 | 顺时针圆弧插补 |
| G03 | 逆时针圆弧插补 |
| G04 | 暂停（Dwell） |

| :--- | :--- |
| G17 | XY 平面 |
| G18 | ZX 平面 |
