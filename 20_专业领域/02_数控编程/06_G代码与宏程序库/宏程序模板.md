# 宏程序模板

## 变量类型（FANUC）
| 变量 | 类型 | 说明 |
| :--- | :--- | :--- |
| #1~#33 | 局部变量 | 仅在当前宏中有效 |
| #100~#199 | 公共变量 | 断电清零 |
| #500~#999 | 公共变量 | 断电保持 |
| #1000~ | 系统变量 | 读写机床参数 |

## 循环模板
```cnc
#1 = 0                     （起始值）
#2 = 10                    （终止值）
#3 = 1                     （步长）
WHILE [#1 LE #2] DO1
  G00 X[#1] Y0
  G01 Z-10 F100
  G00 Z5
  #1 = #1 + #3
END1
```

## 条件判断模板
```cnc
#1 = 20                    （检测值）
IF [#1 GT 10] GOTO 100     （大于10跳转）
G00 X0 Y0
M30
N100 G00 X50 Y50
M30
```

## 椭圆铣削模板
```cnc
#1 = 50                    （长轴半径）
#2 = 30                    （短轴半径）
#3 = 0                     （角度起始）
#4 = 360                   （角度终止）
WHILE [#3 LE #4] DO1
  #5 = #1 * COS[#3]        （X坐标）
  #6 = #2 * SIN[#3]        （Y坐标）
  G01 X#5 Y#6 F500
  #3 = #3 + 1              （步进1度）
END1
```
