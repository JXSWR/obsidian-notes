# 数控编程流程

> 从图纸到上机的完整步骤。

## 第一步：图纸分析
- [ ] 识别材料牌号
- [ ] 标注关键尺寸与公差
- [ ] 识别加工特征（平面/型腔/孔/螺纹/曲面）
- [ ] 确定基准面和定位基准

## 第二步：工艺规划
- [ ] 划分工序（粗/半精/精）
- [ ] 选择机床（参考 [[机床索引]]）
- [ ] 确定装夹方案（参考 [[夹具与装夹方案]]）
- [ ] 编排加工顺序

## 第三步：刀具选择
- [ ] 每道工序匹配刀具（参考 [[刀具索引]]）
- [ ] 设定切削参数（参考 [[材料索引]]）
- [ ] 确定刀具伸出长度

## 第四步：编程与后处理
- [ ] 编写刀路（参考 [[策略索引]]）
- [ ] 后处理配置（参考 [[Cimatron与机床操作]]）
- [ ] 程序头尾规范（参考 [[程序头尾模板]]）

## 第五步：仿真与验证
- [ ] 刀路模拟（过切检查）
- [ ] 碰撞检查（夹具/工件/主轴）
- [ ] 程序单输出

## 第六步：上机调试
- [ ] 首件试切（参数取 70%）
- [ ] 尺寸检测（参考 [[首件检验清单]]）
- [ ] 逐步优化参数

## 第七步：复盘归档
- [ ] 记录实际切削参数
- [ ] 填写 [[复盘笔记模板]]
- [ ] 更新案例库
