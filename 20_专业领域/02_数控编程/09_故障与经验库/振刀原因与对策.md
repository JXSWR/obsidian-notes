# 振刀原因与对策

## 常见原因
| 原因 | 特征 | 对策 |
| :--- | :--- | :--- |
| 刀具悬伸过长 | 低频振动 | 缩短悬伸或使用防振刀杆 |
| 切深不合理 | 特定深度剧烈振动 | 改变切深（避开共振区） |
| 工件刚性不足 | 薄壁处振动 | 辅助支撑/减小切深 |
| 主轴轴承磨损 | 高频振动 | 检修主轴 |
| 刀具磨损 | 声音变尖锐 | 更换刀具 |

## 快速排查
1. 先听声音特征（低频/高频）
2. 检查刀具悬伸量（悬伸 > 4D 时降转速）
3. 调整转速（±20% 避开共振区）
4. 减小径向切宽（动态铣 ae 减小）
