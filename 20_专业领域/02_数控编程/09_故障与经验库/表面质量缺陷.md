# 表面质量缺陷

## 常见缺陷
| 缺陷 | 原因 | 对策 |
| :--- | :--- | :--- |
| 振纹 | 刀具/工件振动 | 见 [[振刀原因与对策]] |
| 接刀痕 | 刀具磨损/路径不连续 | 精加工一次走完不中断 |
| 毛刺 | 刀具钝/进给大 | 换新刀/减小进给/倒角 |
| 表面粗糙度不足 | 步距太大 | 减小步距或换R角更小的刀具 |
| 烧伤变色 | 冷却不足 | 增加冷却/降低转速 |
| 刀痕明显 | 精加工余量不均 | 半精加工均匀余量 |

## 精加工建议
- 精加工前确认刀具状态（全新或未磨损）
- 精加工路径方向一致（避免顺逆铣交替）
- 最后 0.1~0.2mm 作为光刀余量
