# 刀具路径命名规范

## 命名格式
```
[工序号]-[加工类型]-[刀具描述]-[加工面]
```

## 示例
```text
10-RGH-F10-FACE         （10号工序-粗加工-φ10立铣刀-平面）
20-SEM-F8-SIDE          （20号工序-半精加工-φ8立铣刀-侧壁）
30-FIN-B6-CURVE         （30号工序-精加工-φ6球刀-曲面）
40-DRI-D3-DEEP          （40号工序-钻孔-φ3钻头-深孔）
50-TAP-M6-THRD          （50号工序-攻丝-M6丝锥-螺纹）
```

## 缩写标准
| 缩写 | 含义 |
| :--- | :--- |
| RGH | 粗加工 |
| SEM | 半精加工 |
| FIN | 精加工 |
| DRI | 钻孔 |
| TAP | 攻丝 |
| CHM | 倒角 |
| BOR | 镗孔 |
| RGH-FIN | 粗精一体 |
