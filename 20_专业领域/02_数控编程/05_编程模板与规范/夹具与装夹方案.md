# 夹具与装夹方案

## 常见装夹方式
| 方式 | 适用 | 定位精度 | 夹紧力 |
| :--- | :--- | :---: | :---: |
| 精密虎钳 | 方料、板类 | ±0.02mm | 可调 |
| 三爪卡盘 | 轴类、盘类 | ±0.05mm | 可调 |
| 压板+T型槽 | 大型、异形件 | ±0.1mm | 不可调 |
| 真空吸盘 | 薄板、易变形件 | ±0.02mm | 小 |
| 磁力吸盘 | 铁磁性材料 | ±0.03mm | 中 |
| 柔性夹具 | 多品种小批量 | ±0.05mm | 可调 |
| 专用工装 | 大批量 | ±0.01mm | 定制 |

## 装夹原则
- 夹紧点避开加工区域
- 压板高度 ≤ 工件高度 + 5mm
- 避免悬空加工（必要时增加辅助支撑）
- 第一道工序加工基准面和定位面
