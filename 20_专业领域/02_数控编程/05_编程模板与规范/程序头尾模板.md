# 程序头尾模板

## 程序头模板（FANUC 系统）
```cnc
%
O0001（程序名-零件名-日期）
G91 G28 Z0            （安全回零）
G90 G54               （绝对坐标+工件坐标系）
G00 X0 Y0             （定位到原点）
S3000 M03             （主轴转速+正转）
G43 H01 Z100.         （刀长补偿+安全高度）
M08                   （冷却开）
```

## 换刀模板
```cnc
G91 G28 Z0            （抬刀回零）
M01                   （选择性停止）
M06 T02               （换2号刀）
G90 G54               （重新定位）
G43 H02 Z100.         （新刀长度补偿）
S2000 M03
```

## 程序尾模板
```cnc
G91 G28 Z0            （抬刀回零）
G91 G28 X0 Y0         （XY回零）
G49                   （取消刀长补偿）
M30                   （程序结束）
%
```

## 注意事项
- G49 在回零后执行
- M30 前必须抬刀至安全高度
- 程序名与零件名对应
