# 铣刀

## 常见类型
| 类型 | 特点 | 适用 |
| :--- | :--- | :--- |
| 立铣刀 | 平底，侧刃切削 | 开粗、侧壁、型腔 |
| 球刀 | 球头，点接触 | 曲面精加工 |
| 圆鼻刀 | 底部带R角 | 开粗（比立铣刀耐磨） |
| 面铣刀 | 大直径，多刀片 | 大平面铣削 |

## 涂层选择
| 涂层 | 颜色 | 适用材料 |
| :--- | :--- | :--- |
| TiAlN | 紫黑色 | 钢件、不锈钢 |
| TiSiN | 古铜色 | 高硬度钢、钛合金 |
| DLC | 黑色 | 铝合金、有色金属 |
| 无涂层 | 本色 | 普通钢、铸铁 |

## 悬伸原则
- 悬伸量 ≤ 刀具直径 × 4（通用）
- 精加工时 ≤ 刀具直径 × 3
- 侧铣时 ≤ 刀具直径 × 2（大切深）
