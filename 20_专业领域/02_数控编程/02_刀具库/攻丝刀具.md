# 攻丝刀具

## 丝锥类型
| 类型 | 特点 | 适用 |
| :--- | :--- | :--- |
| 螺旋槽丝锥 | 排屑好 | 通孔、盲孔 |
| 直槽丝锥 | 通用 | 通孔 |
| 挤压丝锥 | 无切屑、强度高 | 铝合金、铜 |
| 螺尖丝锥 | 向前排屑 | 通孔 |

## 切削 vs 挤压
| 方式 | 底孔直径 | 螺纹强度 | 适用材料 |
| :--- | :---: | :---: | :--- |
| 切削攻丝 | ≈ 螺纹底径 | 一般 | 钢、铸铁 |
| 挤压攻丝 | ≈ 节径 | 高 30% | 铝、铜、不锈钢 |

## 注意事项
- M6 以下优先用丝锥（成本低）
- M6 以上优先用螺纹铣刀（通用性好）
- 盲孔攻丝底孔深度 = 螺纹深度 + 3~5 牙
