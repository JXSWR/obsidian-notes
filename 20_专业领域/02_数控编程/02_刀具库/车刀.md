# 车刀

## 类型
| 类型 | 用途 |
| :--- | :--- |
| 外圆车刀 | 外圆、端面、台阶 |
| 内孔车刀 | 内孔、内台阶 |
| 切断刀 | 切断、切槽 |
| 螺纹车刀 | 外/内螺纹 |
| 仿形车刀 | 成型面 |

## 刀片材质选择
| 材质 | ISO 代号 | 适用 |
| :--- | :---: | :--- |
| 硬质合金 K 类 | K10~K30 | 铸铁、有色金属 |
| 硬质合金 P 类 | P10~P40 | 钢件 |
| 硬质合金 M 类 | M10~M40 | 不锈钢 |
| CBN | — | 淬硬钢（HRC>50） |
| PCD | — | 铝合金、有色金属 |
