# 钻头与铰刀

## 钻头类型
| 类型 | 适用 | 说明 |
| :--- | :--- | :--- |
| 中心钻 | 打导向孔 60° / 90° | 为大钻头引导 |
| 麻花钻 | 通用钻孔 | HSS / 硬质合金 |
| 枪钻 | 深孔 (L/D > 10) | 需高压冷却 |
| 台阶钻 | 沉孔 + 通孔一次完成 | 批量件 |

## 铰刀
| 类型 | 精度 | 余量 |
| :--- | :---: | :---: |
| 机用铰刀 | H7 | 0.1~0.2mm |
| 手用铰刀 | H6 以下 | 0.05~0.1mm |

## 钻孔注意事项
- 深度 > 3×d 时需啄钻（G83）
- 铸件钻孔后需铰孔去除铸造硬化层
- 不锈钢钻孔需充足冷却，避免加工硬化
