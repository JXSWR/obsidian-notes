# 镗刀

## 类型
| 类型 | 调节方式 | 精度 |
| :--- | :--- | :---: |
| 粗镗刀 | 机械调节 | ±0.05mm |
| 精镗刀 | 微调螺钉 | ±0.005mm |
| 精镗头 | 数显/非标 | ±0.002mm |

## 镗孔余量
| 孔径 (mm) | 粗镗余量 | 精镗余量 |
| :---: | :---: | :---: |
| 20~50 | 0.3~0.5 | 0.1~0.15 |
| 50~100 | 0.5~0.8 | 0.15~0.2 |
| > 100 | 0.8~1.2 | 0.2~0.3 |

## 注意事项
- 精镗前先镗一刀确认同轴度
- 精镗后退刀前主轴停转，避免拉伤
