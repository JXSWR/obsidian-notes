## 建一页机床笔记要记什么

不只是行程和转速。编程真正卡住的是这些：

| 类别 | 参数 | 为什么重要 |
| :--- | :--- | :--- |
| 行程 | X/Y/Z 实际可走范围 | 决定工件能否一次装夹干完 |
| 主轴 | 最高转速、功率、扭矩曲线、锥度（BT40/HSK-A63） | 决定刀柄与切削上限 |
| 刀库 | 刀位数、最大刀径/刀长/刀重、换刀时间 | 决定工序能否一夹完成 |
| 系统 | 法兰克/西门子/三菱、支持哪些循环 | 决定后处理与 G 代码写法 |
| 精度 | 定位精度、重复定位精度 | 决定公差能不能保证 |
| 实测项 | 主轴热漂移、各轴反向间隙 | 老机床必记，影响精加工 |

> 参数来源优先级：**机床铭牌 / 厂家样本 > 系统参数画面 > 自己实测**。
> 三者都不占的，标【待验证】，不要当真值用。
