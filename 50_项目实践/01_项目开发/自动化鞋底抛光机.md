# 自动化鞋底抛光机

> **项目介绍**：双工位二维轨迹 + 对位仪 + 真空吸附的专用自动化抛光设备，集成三台参考设备优点的一体化方案。
> 状态：方案阶段（3D 详细设计进行中）

## 一句话

面向鞋底抛光工序的专用自动化设备，替代人工抛光，兼容 200–360mm 多款式鞋底。

## 核心参数

| 项 | 值 |
|---|---|
| 加工产品 | 鞋底（**200–360 mm** 多种款式） |
| 设备尺寸 | ≤ **2000 × 1800 × 2000 mm** |
| 抛光方式 | **布轮**（8 英寸 / 内孔 25.4 mm）+ 侧面 **3HP 卧式伺服电机** |
| 上料方式 | 人工上料 |
| 夹具方式 | 真空吸 |

## 技术方案要点

**三个参考设备的借鉴来源**

| 来源 | 借鉴内容 |
|---|---|
| 设备一 | 气缸底抛结构布局 |
| 设备二 | 长度计算与居中功能 |
| 设备三 | 真空吸夹具 |

**系统组成**

- **运动系统**：气缸底抛（底部抛光）+ 伺服侧面抛光（3HP 卧式 + 布轮）+ XY 二维轨迹平台
- **定位系统**：对位仪检测鞋底偏移并补偿至 XY 轨迹；长度计算与居中
- **夹具系统**：真空吸（吸附组件材质、密封条槽宽槽深 **待定**）
- **控制系统**：EtherCAT 总线运动控制器，推荐汇川 AC800 系列 / 台达 AX 系列，支持多轴同步与轨迹插补
