# 柔性滑柱仿形夹具

> **项目介绍**：用一片可独立升降的密集滑柱阵列逼近鞋底曲面，锁死后柔性阵列变刚性型腔，配合真空吸附固定鞋底 —— 一套硬件适配 200–360 mm 全鞋码。
> 状态：🟢 进行中（方案阶段，待计算项校核）

## 一句话

面向鞋底抛光工序的通用仿形工装：名称叫夹具，实为参考市面柔性滑柱仿形夹具原理的**仿形定位工装**（不需要夹紧功能）。

## 核心参数

| 项 | 值 |
|---|---|
| 适配鞋码 | **200–360 mm**（鞋底长度） |
| 仿形原理 | 针床式仿形（Pin-Array Conforming），**奇偶行交错密排** |
| 固定方式 | 真空吸附 + 仿形限位 |
| 支撑柱节距 | **8–10 mm** 起步校核 |
| 吸附柱规格 | 外径 **Φ12 mm**，中心气孔 Φ4.2 → **M5×0.8** |
| 吸盘型号 | **SMC ZP2-TS10-GE-A5**（Φ10，导电性 EPDM 海绵） |
| 吸附柱数量 | 5–8 个起步（前掌 1–2 / 足弓 2–4 / 后跟 1） |
| 气源需求 | **仅真空**（锁紧为纯机械，无需锁紧气源） |

## 技术方案要点

**三层功能架构**

| 层级 | 功能 | 内容 |
|---|---|---|
| ① 仿形层 | 贴合鞋底轮廓 | 滑柱阵列 — 支撑柱（多数）被动浮动提供刚性面；吸附柱（少数）密封吸嘴建立真空 |
| ② 锁定层 | 柔性→刚性切换 | 手柄拧紧 → 螺栓下压 → 铁压块横向抱死整排滑柱 |
| ③ 基座层 | 承托 + 气路 | 导向板（定节距）、真空腔、气路分配、传感器 |

**已定技术决策**

| 决策项 | 方案 | 理由 |
|---|---|---|
| 滑柱驱动 | **弹簧复位** | 只把滑柱推回初始高度；贴合靠压紧到位；结构最简单、无额外气源 |
| 柱阵分工 | 支撑柱（多数）+ 吸附柱（少数） | 支撑柱便宜可密排承重，吸附柱只布关键锚点防翘，气路简单 |
| 吸附分区 | 按鞋码分 2–3 组，每组独立气阀 | 远鞋码不盖到的组关阀防漏气，调试量可控 |
| 锁定方式 | 机械手柄 + 螺栓 + 铁压块（按排锁） | 仅需人力，且锁紧力走柱体外壁、真空气路走柱体内孔，**物理隔离** |
| 模块化策略 | **路线 B：增减行模块适配鞋码** | 每排 = 独立模组，基座预留安装孔阵列；足弓区行数不变 |

**动作时序（关键）**

```
放料 → 柱阵浮起轻触 → 压紧到位 → 手柄锁死全部柱（定形）
→ 吸附柱抽真空（拉紧）→ 加工 → 破真空 → 手柄解锁 → 取料
```

> ⚠️ **先锁死、再抽真空**。顺序颠倒会使鞋底被局部吸陷，破坏仿形面。
