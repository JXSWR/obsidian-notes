# 淬锋应用（CimatronE 外挂）

> **产品介绍**：让 CimatronE 工程师少做重复劳动 —— 一键出程式单、批量改 NC 参数。
> 状态：MVP 已跑通，产品化推进中（跨版本兼容 / 授权 / 打包）。

---

## 解决的痛点

CimatronE 模具/五轴编程里两类重复劳动最费时：

- **程式单输出**：每个 NC 程序都要列 TP/刀具/转速/进给，截视图、排版、出 Excel —— 一个典型五轴工件 30~80 个 TP，手动排程单能占半天
- **加工参数批量调**：转速/进给/余量/安全高度要按区域或刀具批量改，CE 自带表格零批量能力，改一个跳一个对话框

淬锋应用把这两件事做成 **CimatronE 内的命令**，点一下就出。

## 核心卖点

| 功能 | 替代什么 | 节省什么 |
| :--- | :--- | :--- |
| **一键出程式单（Excel 版）** | 手动截图 + 排版 + 出 Excel | 一工件 0.5~2 小时 |
| **NC 参数批量编辑器** | 单对话框逐项改 | 一工件 30~60 分钟 |
| **淬锋应用统一面板** | 工具栏 / 菜单散落查找 | 一处整合所有功能 |

输出是 **白底工程图式 Excel**（手写 OOXML，零 Excel 依赖），CE 里点命令 → 直接得到能交付的程式单。

## 与同类产品的差异

参考标杆是**口口外挂**（模具圈事实标准，C++ 开发，单人作者）。淬锋应用差异化点：

| 维度 | 口口外挂 | 淬锋应用 |
| :--- | :--- | :--- |
| 开发语言 | C++（贴近 Cimatron 内部） | **C# + .NET Framework 4.8**（门槛低、易维护） |
| 程式单输出 | 多格式 | **Excel 版为主**，白底工程图式 |
| 中文帮助 | 无 | **外挂内嵌 NC 中文帮助（路线 B）**，覆盖率 87% |
| 授权模型 | 待验证 | **机器指纹 + RSA 验签**（设计中） |

## 技术栈（C# 路线，已跑通）

- **开发环境**：Visual Studio 2022 Community（.NET Framework 4.8，C# 类库）
- **API 接入**：CimatronE 官方 COM interop（CimNcAPI / CimBaseAPI / CimServicesAPI 等）
- **命令注册**：`Register_API_Commands.exe`（CE 自带注册工具，已实测）
- **Excel 生成**：自研 `XlsxWriter.cs`（手写 OOXML + `System.IO.Compression`，零第三方依赖、不要求装 Excel）
- **中文帮助**：`hhc.exe` + Node.js 脚本链，覆盖率 **932/1074 ≈ 87%**

## 适合谁 / 不适合谁

**适合**：
- CimatronE 模具/五轴编程工程师 / 工坊主
- 有重复程式单输出的团队（一个工件 50+ TP 的）
- 想用中文 CE 帮助的工程师

**不适合**：
- 用 NX / Mastercam / UG 的用户（本外挂只接 CimatronE 2024）
- 期望"开箱即用"的产品（当前仍需手动部署）
