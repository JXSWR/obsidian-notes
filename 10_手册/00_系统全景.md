```

    ├── settings.json         ← permissions.deny 硬拦截（60_存档、_原始资料、.git）

    │   ├── design-solver.md  ← 非标设计领域知识骨架
    │   └── learning-coach.md ← 跨领域学习教练
    └── commands/
        └── review.md         ← /review 非标设计方案五维评审

C:/Users/BEER/.codebuddy/    （用户级，全局生效）
├── rules/obsidian-vault.md   ← 双位置约定（位置指针：vault 只放 md，执行文件在 D:\repos\My project workspace）
└── settings.json             ← additionalDirectories（vault + D:\repos\My project workspace）
```

### 扩展机制总览（WorkBuddy 原生）

| 机制 | 用途 | 本系统用法 |
| :--- | :--- | :--- |
| **Sub-agents** | 隔离上下文执行专门任务 | 3 个：cnc-programmer / design-solver / learning-coach（`.codebuddy/agents/`） |
| **斜杠命令** | 一键触发的固定流程 | 1 个：/review（`.codebuddy/commands/`） |
| **规则 rules** | 模块化提示式规则 | SYSTEM.md（项目级权威）+ obsidian-vault.md（用户级指针） |
| **permissions.deny** | 确定性强制拦截 | 硬拦 60_存档、_原始资料、.git 的写入 |
| **官方插件** | 文档/浏览器等能力 | pptx / pdf / docx / xlsx / playwright-cli 等（`enabledPlugins`） |

**分工原则**：领域知识→Sub-agents，固定流程→斜杠命令，提示式约定→rules，确定性强制→permissions.deny。MCP 已全部废弃，检索用原生 Grep/Glob/Read。

| `40_自媒体/` | ✅ | ✅ | 内容生产 |

| `assets/` | ❌ | ✅ | 按需查找 |
| `scripts/` | ❌ | ✅ | 本地脚本 |

### 写保护（permissions.deny）

`.codebuddy/settings.json` 的 `permissions.deny` 规则在 `Edit|Write` 前原生拦截对 `60_存档/`、`20_专业领域/01_非标设计/_原始资料/`、`20_专业领域/02_数控编程/_原始资料/`、`.git/` 的一切写入。这是确定性强制——不同于 SYSTEM.md 的提示式权限矩阵，deny 规则 100% 阻止、不可绕过、可审计（`/permissions` 面板查看）。

### 压缩指令（定义于 CODEBUDDY.md）

```
/compact 时保留：当前任务目标、关键决策及理由、未完成的待办。
丢弃：搜索中间结果、已解决的报错详情、已读取过的文件全文。
```

## 四、检索路由

```
用户提问涉及专业知识
    ↓
1. 读对应领域 00_全局/索引.md → 匹配关键词找到目标文件
2. 读目标文件获取完整内容
3. 索引覆盖不到时 → 用原生 Grep 全文搜索补充
```

## 五、安全层

`.gitignore` 保护：

- 密钥与凭证：`.env`、`.env.*`、`*.pem`、`*.key`
- OS 隐藏文件：`.DS_Store`、`Thumbs.db`、`desktop.ini`
- 依赖：`node_modules/`、npm/yarn 日志
- Obsidian 内部：`.obsidian/`
- 编辑器临时文件 + 本地脚本输出
- 大型二进制（CAD/3D）：`*.SLDASM`、`*.SLDPRT`、`*.STEP`、`*.dwg`、`*.zip`、`*.pdf` 等
- WorkBuddy 工作区：`.workbuddy/`

## 六、记忆系统

Typed Memory（`~/.codebuddy/projects/.../memory/`），四类结构化记忆，跨会话自动注入：

- `user` — 用户身份、角色、知识边界
- `feedback` — 用户纠正与确认的协作偏好
- `project` — 项目背景、决策、动机
- `reference` — 外部系统资源指针
