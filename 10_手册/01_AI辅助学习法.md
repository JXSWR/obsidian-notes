# 🎓 AI 辅助学习法（六步 + 五步）

> 系统内调用：`/agent @learning-coach`
> learning-coach 是**元工具层（全局 Sub-agent）**，不绑定任何知识库，跨领域服务。
> 管辖级别同领域 Agent，作用域覆盖所有领域。

---

## 方法对比

> `@learning-coach` 支持两类学习方法，**由你决定用哪个**。

| | 🏗️ 六步法 | 🧠 五步法 |
|---|---|---|
| 一句话 | 系统学一门新技能，记得住讲得出 | 快速理解概念，抽象结构并迁移 |
| 独特武器 | 速查表、费曼循环 | **提取结构四步法**（去表象→抓要素→理关系→做抽象） |
| 通用步骤 | 阶梯 → 核心 → 考官 → 速查 → 筛资源 → 费曼 | 阶梯 → 输入 → 考官 → 提取结构 → 实战迁移 |
| 参考笔记 | 本篇 | 本篇 |

## 完整学习流

```text
你说"想学XX"
    ↓
① 拆等级 → 画地图
    ↓
② 提取20%核心 → 排10次×2小时
    ↓
③ 每学完一个模块 → 考官测试 → 暴露缺口
    ↓
④ 每学完一个主题 → 压缩速查表
    ↓
⑤ 需要资源时 → 筛5个最佳 → 排7天路径
    ↓
⑥ 感觉不稳时 → 费曼循环 → 讲到真懂
    ↓
      ↺ 循环迭代 ↺
```

## 🧠 五步法详解

> 适用：快速理解一个概念/主题，抓住底层结构并迁移到新场景

|  #  | 方法           | 一句话                           | 什么时候用 |
| :-: | :----------- | :---------------------------- | :---- |
|  ①  | **搭学习阶梯**    | "拆成5个等级，从新手到独立做项目"            | 开始前   |
|  ②  | **筛资源 + 输入** | "筛选最佳资源，按阶梯学一遍，总结章节核心"        | 学习阶段  |
|  ③  | **AI 考官**    | "逐题测试，暴露知识缺口"                 | 学完后   |
|  ④  | **提取结构**     | "[[02_提取结构四步法]]：去表象→抓要素→理关系→做抽象" | 建模时   |
|  ⑤  | **实战迁移**     | "换一个类似但不同的题目，用同一底层结构去解"       | 验证理解  |

### 五步学习流

```text
你说"想搞懂XX概念"
    ↓
① 搭阶梯 → 画地图
    ↓
② 筛资源 + 输入 → 边学边总结核心
    ↓
③ 考官测试 → 暴露缺口
    ↓
④ 提取结构 → 去表象→抓要素→理关系→做抽象
    ↓
⑤ 实战迁移 → 换题用同一结构 → 真正内化
    ↓
      ↺ 循环迭代 ↺
```

### ④ 提取结构（四步一体核心）

> 详见 [[02_提取结构四步法]]

| 步骤 | 动作 | 追问 |
|:---:|:---|:---|
| 去表象 | 剥掉话术、形式、场景 | "去掉包装，还剩什么？" |
| 抓要素 | 找出缺一不可的 3-5 个核心点 | "少了哪个就不成立？" |
| 理关系 | 理清因果、先后、循环、对立 | "它们怎么互相推动？" |
| 做抽象 | 浓缩成可迁移的极简模型 | "换领域还能用吗？" |

**检验标准**：要素完整？关系清楚？可以迁移？

> 所有具体事物都是"1 个结构 + N 层皮"。拆到骨架，换领域只需换皮。
> 学完这个技能后，下次你能自己用这套方法学新东西。
