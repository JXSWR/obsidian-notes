# Windows 11 垃圾清理指南

> 来源整理：基于 AI 问答归纳（Windows 11 自带清理工具）

## 核心结论

Windows 11 自带功能完全够用，**不需要安装任何第三方清理/管家类软件**。

系统自带的职责划分：

| 功能 | 负责方 | 入口位置 |
|------|--------|----------|
| 杀毒防护 | Microsoft Defender | Windows 安全中心 |
| 垃圾清理 | 存储感知 + 磁盘清理 | 设置 → 系统 → 存储 |

---

## 三种清理方法（由推荐到手动）

### 1. 存储感知（首选 · 自动）

- 路径：**设置 → 系统 → 存储 → 打开「存储感知」总开关**
- 可设置清理频率（建议选「每周」）
- 可勾选「自动清理下载文件夹」（建议选「从不」，防止误删重要文件）
- 开启后，本地长时间未打开的云内容会自动转为「仅在线版本」，节省磁盘空间

### 2. 手动快速清理（最直接）

- 路径：**设置 → 系统 → 存储 → 点击「临时文件」**
- 勾选要删除的项（如 Windows 更新清理、临时文件、回收站等）
- 点击「删除文件」即可

### 3. 经典磁盘清理（依然可用）

- 开始菜单搜索「磁盘清理」→ 打开 → 选择磁盘 → 勾选要清理的项 → 扫描并删除
- 适合清理占用空间较大的旧安装文件、更新残留等

---

## 为什么自带工具比第三方软件更强

### 实际效果参考

一次完整清理可释放 **约 50GB** 系统盘空间，这主要是 **Windows 更新备份文件和旧版系统文件**——它们是占用空间最大的「大块头」，也是第三方工具不敢碰的。

### 杀毒 vs 清理：分工不同

| 类型 | 职责 | 代表 |
|------|------|------|
| 杀毒软件 | 干掉病毒、木马等外部威胁 | Defender / 360 等 |
| 清理工具 | 扫除系统缓存、临时文件等内部垃圾 | 存储感知 / 磁盘清理 |

对于不胡乱下载的干净电脑，**系统垃圾才是吃掉空间的「元凶」，而不是病毒**。

### Windows 自带工具的两个核心优势

#### 1. 最懂自己的「家务清单」

Windows 系统极其复杂，文件关联环环相扣，只有微软自己最清楚：

- **哪些备份文件可以删？** 比如某次更新的回滚备份，系统知道这是为卸载准备的，删了只会让更新无法回退（但不会让系统崩掉）
- **哪些临时文件正在用？** 某个看起来像垃圾的 `.tmp` 文件，可能正被系统进程占用。第三方软件若强行删除会蓝屏报错；而系统自带工具会直接跳过
- **哪些是安全边界？** 这是底线。很多打着「深度清理」旗号的软件，为了显得自己厉害，会删除字体缓存、驱动备份等，当时腾出空间却给未来埋下隐患

> 之前提到杀毒清理软件不管用，正是因为它们怕出事，只能清理最基础、最明显的缓存，对 Windows 更新这类「大块头」根本不敢碰。

#### 2. 和系统是一家人，清理得心应手

第三方软件是「外人」，只能通过公开接口扫描。而磁盘清理是系统的一部分，能：

- **直接调用底层权限**：比如处理 WinSxS 组件存储（一个动辄几十 GB 的系统核心文件夹）时，系统可以精细到只通过硬链接删除冗余，丝毫不影响功能
- **维护系统健康**：清理只是其一。像存储感知还能自动维护系统健康，这是第三方工具无法嵌入的生态闭环

所以这种深入到系统机理的清理，本身就是在正确和安全上做到了极致——这正是「原厂」才有的底气和优势。

---

## 一句话总结

> **Windows 安全中心（杀毒） + 存储/磁盘清理（清垃圾） = 完整方案，干净又省心。别装第三方管家类软件。**
