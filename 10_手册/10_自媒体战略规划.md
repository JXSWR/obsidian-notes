# 自媒体战略规划

> 整理日期：2026-08-20
> 状态：战略层已闭环，待第一条内容落地

---

## 一、战略定位：资产化变现，不做「接单」

**核心判断**：接单 = 在家打工，本质仍是卖时间。自媒体真正的战略意义，是把「一对一卖时间」升级为「一对多卖资产」。

### 变现漏斗（从上到下，是先后关系，不是并列选项）

```
顶层  课程 / 付费咨询      ← 复利资产（后置，等信任够了再上）
中层  接单 / 数控外包      ← 现金流（非目的）
底层  案例库 + 短视频      ← 引流 + 信任品（前置）
划掉  流量分成 / 广告      ← 小众垂类，不成立
```

- **接单的新定位**：从「目的」降级为「内容副产品」——同一段硬核专业内容，工程师看到想学、老板看到想外包。
- **一句话本质**：自媒体全部价值 = 把 20 年经验从「只能一次卖给一个客户」，变成「能同时卖给一百个人」。

---

## 二、目标用户：想入行、想涨薪的机械工程师 / 学生

- **痛点**：不知道怎么入行 / 转行；工作几年遇瓶颈想涨薪；学生面临就业焦虑。
- **付费能力**：在职工程师（涨薪 / 跳槽动力）> 学生（基数大、就业焦虑强）。
- **盘子评估**：机械 / 制造从业者上千万；机械专业年毕业生几十万；该细分**尚无真正头部**，存在空缺机会。

## 三、平台策略：B站主阵地 + 一鱼两吃分发

| 平台 | 定位 | 动作 |
|---|---|---|
| **B站** | 主阵地 | 全力做长视频 |
| 视频号 | 私域承接 | 视频原样发 |
| 知乎 | 文字承接 | 口播稿改文字版 |
| 抖音 / 小红书 | 暂缓 | 需专门重做，冷启动不碰 |

**原则**：核心内容只「创作」一次，其他平台只「分发」不「重做」。区分「创作」与「分发」，是防止多线分散的关键。

---

## 四、冷启动打法：先单点验证，不先定大纲

- **不做系统课、不先定大纲**——大纲由数据反推，而非拍脑袋。
- 先做 3~5 条「单点选题」验证市场，哪条爆了就是方向。
- **先单后扩（同心圆）**：

```
内核（不变）：你这个人 —— 20年非标 + 数控、敢说真话、正在转型
第①圈（现在）  机械工程师/学生 → 技术 + 入行涨薪
第②圈（打穿后）泛制造业技术人 → 数控、工艺、自动化
第③圈（再扩）  想转型/搞副业的技术人 → 一人公司转型实录
第④圈（远期）  泛职场/成长人群 → 认知、修行、搞钱思考
```

- **警惕**：多平台多人群是「扩张期」的事，不是冷启动起点；「单一」不是风险，「做不深」才是。

## 五、内容架构：两硬一软

| 资产 | 角色 | 用法 |
|---|---|---|
| **非标设计** | 主线（术） | 项目拆解、设计方法、避坑 |
| **数控编程** | 辅线（术） | 差异化武器，全链路视角 |
| **觉知** | 人格底色（道） | 只渗透，不单独做 |

- **差异化壁垒**：讲设计的人多、讲加工的人多，但「设计 + 加工全链路都懂」的人稀缺。
- **主线为什么是非标设计**：它是身份锚点、20 年主业；知识付费天花板设计 > 编程；若以编程为主线反而降维。
- **觉知为什么不单独做内容线**：讲大道理易翻车、无变现基础、稀释定位。
- **完整人设一句话**：一个干了 20 年非标设计 + 数控编程的老师傅，既懂设计又懂加工，而且看问题总比别人透一层。

## 六、人设：真实人设就是素材

- 警惕「IP 打造的完美主义」，真实人设本身就是素材。
- 最稀缺素材 = 「20 年技术人如何转型一人公司」的过程本身（而非单纯技术干货）。
- 流量与挣钱不丢人，但要用「真实的自己」获取，而非「包装的人设」。

## 七、内容形式：结构级选题 + 录屏口播

- **选题**：结构级（单点小问题，5~8 分钟），不是设备级（整台设备，太耗时）。

| 结构级（做） | 设备级（不做） |
|---|---|
| 「丝印机的对位结构，为什么总跑偏」 | 「双通道丝印机整机怎么设计」 |
| 5~8 分钟讲透 | 30 分钟打不住 |

- **形式**：SolidWorks 录屏 + 自己的口播，**不出镜**。
- **铁律**：
  - 声音用真人声，绝不用 AI 配音（AI 味最大来源）。
  - 画面用真实素材（录屏 / 实拍 / 真实图纸）。
- **「人味」三来源**：真实声音 + 真实画面 + 真实经历（三者都具备）。
- **内容原则**（做每条内容的底线）：**简洁 · 高质量 · 纯干货**。
  - 不堆时长、不灌水、不凑数——能 5 分钟讲清的，绝不拖到 10 分钟。
  - 每条都奔着「看完有所得」去，没有信息增量的片段一律砍掉。

### 内容红线（不可碰）

- **不分发破解 / 盗版软件**：SolidWorks 是商业软件，发出去安装包、破解补丁、序列号生成器 = 侵犯著作权，违法且违反 B站规则。
- **不用「发安装包」当吸粉钩子**：不写「三连扣 666 / 私信免费领安装包」这类话术，不组织分发破解资源。此类视频往往先涨粉后遭批量下架 + 封号，地基不干净，且吸来的是「白嫖粉」而非「专业粉」，与「技术 IP」定位背道而驰。
- **激活演示不下场**：视频里不演示破解激活流程、不给破解链接。讲「版本怎么选 + 安装流程 + 报错解决」即可。
- **正版替代钩子**：评论区置顶放「正版获取渠道」（学生教育版 / SolidWorks for Makers 个人版 / 官方试用），既留住观众又合规。
- 理由：靠真实经验与专业判断吸粉，才撑得起「一人公司 / 技术长视频」的长期规划；靠资源号起量，号随时可能归零。

## 八、内容生产流程

- **写稿 ≠ 念稿 ≠ AI 味**：提纲是把「心里的货」翻译成「别人听得懂的话」的翻译器。
- **分工**：用户负责「倒素材」（哪怕逻辑混乱），AI 负责「理结构」。

```
提纲结构：
① 钩子（一句话，把人留住）
② 3 个要点（对着要点，用自己的大白话展开）
③ 升华（一句看透本质的话）
```

- 新手「随便播」三坑：跑题 / 啰嗦 / 没钩子收尾。
- 「随便播」是内化结构之后的状态，非零基础起点。
