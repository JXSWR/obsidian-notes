## 二、WorkBuddy 桌面端（主力）

### 📥 安装

- **下载**：https://www.codebuddy.cn/work/
- **登录**：微信 / QQ 扫码
- **福利**：注册后去个人中心手动领 5000 新用户积分（90 天有效），每月另有 500 免费额度

### 🚀 上手要点

1. **三种模式**（省积分关键）：
   - **Ask（问答）** → 只聊天，不动文件，不费积分
   - **Plan（规划）** → AI 先出方案，确认再执行
   - **Craft（实干）** → AI 直接动手（默认），费积分高
2. **文件管家**：拖文件进对话区，让它读/编辑/生成 Word/Excel/PPT/PDF
3. **定时任务**：大白话描述即可（例：每周一 10 点整理上周项目进展生成周报）
   > ⚠️ 客户端需保持运行，完全退出不触发
4. **需求黄金公式**：**操作对象 + 具体动作 + 输出位置 + 边界条件**
   > 例：「读取这个 BOM.xlsx，按供应商分组统计采购件数量，结果存 `50_项目实践/`」
5. **快捷键**：`/` 调技能或命令，`@` 引用文件

### 🧩 可用技能 / 命令

| 类型   | 名称                                                | 用途                                     |
| :--- | :------------------------------------------------ | :------------------------------------- |
| 技能   | `xlsx` `docx` `pptx` `pdf`                        | 读写 Office / PDF                        |
| 技能   | `playwright-cli` `agent-browser`                  | 网页自动化、截图                               |
| 技能   | `find-skills` `loop`                              | 找新技能 / 定时循环任务                          |
| 项目命令 | `/review`                                         | 自定义评审（`.codebuddy/commands/review.md`） |
| 子代理  | `design-solver` `cnc-programmer` `learning-coach` | 非标设计 / 数控编程 / 学习教练                     |
|      |                                                   |                                        |

## 三、双工作空间（核心约定）

| 场景 | 工作空间选 | `pwd` 实测结果 | 加载什么 |
| :--- | :--- | :--- | :--- |
| **日常问答** | `D:\workspace\workbuddy` | `D:\workspace\workbuddy\2026-09-02-23-07-51`（会话级，按时间戳分目录） | 只加载**用户级**规则（3 行位置指针） |
| **项目 / 产品开发** | `d:\My knowledge vault`（vault） | `D:\My knowledge vault` | **全套**：`SYSTEM.md` + 3 个 agent + `/review` + `deny` 硬拦截 |

**执行文件位置**：`D:\repos\My project workspace\`（代码、脚本、git 仓库、CAD）
> vault 内 `50_项目实践/` 只放 `.md` 引用，不放执行文件（已在 `settings.json` 的 `additionalDirectories` 里放行）。

**验证方式**：换工作空间后发 `pwd`，看返回值即可确认哪套规则生效。已实测两边均符合预期。

## 四、配置分层

| 层级 | 路径 | 生效范围 | 放什么 |
| :--- | :--- | :--- | :--- |
| **用户级** | `C:\Users\BEER\.codebuddy\rules\` | 所有工作空间 | 只放位置指针（vault 在哪、执行文件在哪） |
| **项目级** | `d:\My knowledge vault\.codebuddy\` | **仅 cwd 指向 vault 时** | `SYSTEM.md`（权限矩阵）、agents、commands、`settings.json` |

> ⚠️ 项目级规则**不向上查找**——cwd 不在 vault 就全部静默失效，不报错。所以用 `pwd` 确认是必要动作。

## 五、权限护栏（`settings.json` 的 deny）

以下目录**硬拦截写入**，AI 改不动：
