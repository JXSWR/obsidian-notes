# 📥 收件箱 — Capture Inbox

> **新信息的临时缓冲区。** 不思考"放哪里"，先丢进来再说。
>
> 原则：每周分流一次，清空收件箱。

## 使用规则

| 动作 | 说明 |
| :--- | :--- |
| **收** | 看到好文章、截图、灵感、聊天记录，无处安放时先丢这里 |
| **分** | 处理时先判类：已覆盖 / 原文归档 / 蒸馏成稿 / 无法蒸馏 / 行动项（判据见 [[蒸馏归档]]） |
| **蒸** | 有增量的素材提炼成结构化笔记，按目的地模板归位 → [[蒸馏归档]] |
| **清** | 收件箱应为空或接近空（< 5 条）才健康 |

> ⚠️ **随笔记.md 例外**：它是用户私人随手记（自留地），**独立存在、不参与分流、不做清理对象**。每次整理与健康度统计都跳过它。
