## 四、硬约束与教训

- **积小步提交（9-04 事故）**：磁盘 38 个 md 被删，全靠 git 暂存区找回（`git ls-files -d | git checkout-index`）。**暂存区=免费快照层**；未跟踪文件（07 五卡）真无解。**每步重组就喊 AI「固化」**。
- **体积/文件数/目录结构一律用 Python**（`os.walk` + `getsize`）：`find`/`awk`/`du -sh` 对中文路径均不可靠（同一目录 du 给过 35M 与 253M）。评估目录结构必须全量遍历，勿用带 limit 的 Glob。
- **git 中文路径必须加 `-z`**：`git ls-files` 默认转义成八进制（`20_\344\270\223…`），Python 按该串 `isfile` 判 False → 静默跳过（9-05 扫描 239 文件只扫到 20，假阴性）。
- **`.gitignore` 匹配大小写敏感**，只写一种形式必漏（曾漏 3 个大写 `.PDF`）；另挡 `*.xlsx` → 3 个 xlsx **零 git 备份**：04_查询库 `最强非标自动化计算表格.xlsx`（31 MB，唯一副本）、`时序图表格.xlsx`、60_存档 `BOM分类汇总对比表.xlsx`。
