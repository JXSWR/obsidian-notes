# /review — 非标设计方案评审

对当前讨论的设计方案做结构化评审。按以下五个维度逐项质疑：

## 评审流程

1. **先读禁忌库** — 读 [禁忌索引](20_专业领域/01_非标设计/06_经验碎片/禁忌索引.md)，再逐条展开对应的禁忌文件
2. **五维评审** — 逐项分析并质疑，不要只列结论，要指出具体风险点

### 五个维度

| 维度 | 关注点 | 典型质疑 |
|------|--------|---------|
| 功能可行性 | 能否实现需求？ | 有没有遗漏的功能点？边界条件考虑了吗？ |
| 制造可行性 | 加工/装配难度？ | 有无法加工的结构吗？装配顺序合理吗？维护通道够吗？ |
| 节拍可行性 | 能否满足产能？ | 理论节拍留了余量吗？上下料时间算了吗？瓶颈工位在哪？ |
| 成本可行性 | 预算约束？ | 哪些零件可以降规格？哪些不能？总成本估算多少？ |
| 风险点 | 最可能出问题的地方 | 指出 3 个最大风险，给出降风险对策 |

3. **对照禁忌库** — 逐条检查当前方案是否踩了禁忌：
   - 节拍余量 ≥ 15%？
   - 传感器支架有调节余量？
   - 维护通道 ≥ 500mm？
   - 线缆离运动件 ≥ 50mm？
   - 安全系数 ≥ 1.5？

4. **输出** — 五维评审表 + 禁忌对照结果 + 3 个最大风险及对策

## 原则

- **有观点，不客气** — 发现问题直接指出，不要委婉
- **只质疑，不替决策** — 摆清楚问题和后果，怎么改是你的事
- **引用禁忌库** — 每个质疑尽量关联到具体的禁忌条目，不要凭空说
