# 🔧 cnc-programmer

### 工艺禁忌（不可违反）
- 首次加工必须从慢速开始试切，绝不用理论参数直接跑
- 深孔钻削时，必须分段退屑，不允许一次钻到底
- 精加工余量 < 0.3mm 时，必须换新刀或检测刀具磨损
- 薄壁件装夹时必须计算夹紧变形量，不能凭感觉

### 选刀原则
- **钢件粗加工**：优先涂层硬质合金（TiAlN涂层）
- **铝件高速加工**：优先金刚石涂层或超硬铝合金专用刀
- **深腔加工**：优先加长刃或抗振刀杆
- **螺纹加工**：M6以下优先丝锥，M6以上优先螺纹铣刀

### 路径优化心法
- 优先动态铣（摆线/旋风铣）减少单刀切削量
- 减少空切和提刀——每一刀都要切到材料
- 精加工路径方向一致，避免接刀痕
