# OBS 录屏指南（SolidWorks 教程向）

> 适用：录 SolidWorks 安装 / 操作 + 真人声口播
> 原则：内容我备，录制你点。本指南只管「怎么把屏幕和声音干净地录下来」。

---

## 一、安装

- 官网 obsproject.com 下载 Windows 版，装好打开。
- 首次弹「自动配置向导」→ 选 **「优化用于录制」** → 分辨率用屏幕原生（通常 1920×1080）→ FPS 选 **30**（教程不用 60）。

---

## 二、建场景与来源（最关键）

左下「来源」区点 **+** 加两个来源：

1. **显示器采集**（录整个屏幕）
   - 来源 → + → 显示器采集 → 确定 → 选常用屏 → 确定
2. **音频输入采集**（录人声）
   - 来源 → + → 音频输入采集 → 确定 → 设备选你的麦克风 → 确定

> 只想录 SW 窗口可换「窗口采集」选安装程序；但安装会弹多个窗口，新手用显示器采集最稳。

---

## 三、音频滤镜：过滤杂音（核心）

混音器里麦克风那行 → 点 **⚙ 齿轮 → 滤镜** → 左下 **+**，按顺序加三层：

| 顺序 | 滤镜 | 设置 | 作用 |
| :--- | :--- | :--- | :--- |
| 1 | **噪声抑制** Noise Suppression | 类型选 **RNNoise** | 吃掉空调/风扇/电流底噪 |
| 2 | **噪声门限** Noise Gate | 关闭阈值 ≈ -45~-40 dB；打开阈值 ≈ -35 dB | 不出声时静音，挡键盘/呼吸声 |
| 3 | **增益** Gain | +6~+10 dB | 补回前两步削掉的音量，别过猛 |

> 顺序必须是：抑制 → 门限 → 增益，从上到下。顺序错效果打折。

### 关掉会进麦的杂音源（源头更要掐）
- **桌面音频静音**：混音器点桌面音频小喇叭 → 安装提示音/网页声不进录音
- **关通知**：录前关微信/QQ/邮件通知，防弹窗声
- **物理降噪**：麦远离空调出风口；加防喷罩；录音别碰桌子（悬臂架/垫海绵）

### 自检
加完滤镜，正常说话 + 故意敲桌子/开风扇：
- 说话时绿条动、安静时基本不动 = 门限对了
- 回放底噪明显变小 = 抑制对了

---

## 四、画质设置（一次就好）

右下「设置」→ **输出**（简单模式）：
- 录制格式：**mp4**（B站直接认）
- 视频比特率：8000–12000 Kbps
- 编码器：**硬件**（NVENC / AMF / Apple），走显卡不卡

→ **视频** 标签：基础/输出分辨率 1920×1080，FPS 30。

---

## 五、开录

1. 点右下 **「开始录制」**（不是「开始直播」）
2. 正常操作 + 边做边讲
3. 录完点 **「停止录制」**
4. 文件默认在 `此电脑\视频\OBS\`

---

## 六、本类视频实操建议

- **先空跑一遍**再正式录：边讲边点容易卡壳，顺顺嘴
- **人声距离** 15–20cm，喷麦套袜子/防喷罩
- **讲错别停**：录完用剪映 / B站「云剪辑」剪口误，比重录省事
- 不出镜、不 AI 配音（战略铁律：真人声 + 真实画面）

---

## 七、后期剪辑：剪映电脑版（专业版）

> 录屏 + 配图 + 结尾字幕，全用**电脑版剪映**，不用手机版（素材是 1080p 桌面录屏，手机版卡且传文件麻烦）。

### 为什么用电脑版
- 多轨道叠配图 / 画中画 / 结尾字幕，大屏对齐更准
- 直接吃 OBS 的 mp4，不用来回传手机

### 基本流程
1. 打开剪映专业版 →「开始创作」→ 导入 OBS 的 mp4
2. 拖到轨道，剪掉口误 / 停顿（按 `S` 切刀，`Delete` 删）
3. 加配图：媒体 → 导入图片 → 拖到视频轨上方「画中画」→ 对齐讲到那段的时间点 → 拖两端改时长
4. 加结尾字幕：「文本」→ 加「点赞·投币·收藏→不迷路」→ 放底部、调字号色（呼应封面工业橙）→ 停 2–3 秒

### 导出设置（关键，别默认）
- 分辨率：**1080p**（与 OBS 一致，不二次压缩）
- 格式：**MP4**
- 帧率：**30**
- 码率：选「推荐」或手动 8000–12000（和录制同级，画质不掉）
- 导出位置默认 `此电脑\视频\`

> 导出完直接传 B站，不用再转格式。
