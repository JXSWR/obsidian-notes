# 💬 视频号

> 微信生态私域阵地,适合「熟人/转发裂变」的中短视频。

## 平台定位
- 依托微信社交链,熟人 + 半熟人分发
- 转发率高,适合"给同行/客户看"的专业内容
- 可从公众号、朋友圈、社群导流

## 内容形态
- 中短视频(1–3 分钟)
- 可由 B站长视频切片,或公众号文章转视频

## 时长 / 字数
- 视频 1–3 分钟
- 文案中等,偏口语

## 调性关键词
专业 · 可信 · 可转发 · 熟人感 · 实用

## 适配你的内容方向
- 「非标自动化」客户向精简版
- 凸轮分割器选型避坑(给采购/同行看)
- B站/公众号内容的视频号切片

## 发布清单
- [ ] 竖屏 9:16 或 1:1
